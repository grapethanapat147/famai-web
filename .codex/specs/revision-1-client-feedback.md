## A. Cross-cutting (ทำเป็น convention ใช้ทุกหน้า)

1. **Confirm popup ก่อนบันทึก/ส่งออกทุกหน้า** — "ข้อมูลถูกต้องแล้วใช่ไหม" → คอมโพเนนต์ `ConfirmDialog` (ต่อยอด FAM-1003) + ใช้ทุก mutation/export
2. **หน้าข้อมูลปริ้นซ์ได้** — ใบเสร็จ/รายละเอียดการชำระ/คำนวณค่างวด ต้องพิมพ์ได้ (print CSS + server PDF)
3. **ช่อง "หมายเหตุ" (note)** — เพิ่มได้หลายจุด (ขาย, ค่าใช้จ่าย, ลา, ส่งมอบ ฯลฯ)
4. **Flow อนุมัติโดยการเงิน** — การเงินเข้ามากด "ถูกต้อง/ผ่าน" (ขายรถ, ค่าใช้จ่าย) — schema มี `sale.payment_confirmed_by` อยู่แล้ว
5. **Design ทั่วไป:** ตัวอักษรใหญ่ขึ้นอีกนิด + minimal มากขึ้น

## B. โครงสร้างที่กระทบ schema (ต้องตัดสินใจก่อน — DB "เสร็จ" แล้วแต่ต้องแก้)

### B1. บริษัท > สาขา (BIG) 🔴
- รับรถ/บันทึกเข้าสต๊อก: เปลี่ยน "สาขา" → **"บริษัท"** แล้วเพิ่มหัวข้อ **"สาขา"** ถัดไป
- ขายรถ: เพิ่มเลือก **บริษัท + สาขา**; ถ้าเลือกสาขา/รุ่นผิด → เตือน "เลือกไม่ตรงกับสาขาที่อยู่ ให้ย้ายรถก่อน"
- โอนย้าย: **บริษัท→บริษัท ทำไม่ได้** ต้อง "เปิดการขายระหว่างบริษัท" (เปิดบิลก่อน); ใต้บริษัทเดียวกัน = ย้ายตามสาขาได้ (สาขากรอก manual ได้)
- → **ตีความ:** ต้องเพิ่ม entity `company` เหนือ `branch` (ปัจจุบัน DB มีแค่ `branch` ที่มี `tax_id`/`branch_no`) · RLS/เอกสาร/ตัวนับเลข ผูกกับบริษัท · โอนข้ามบริษัท = ธุรกรรมขาย
- **ต้องถามลูกค้า:** มีกี่บริษัท · FMG01/FMM01/FCG01 เป็นคนละบริษัทหรือบริษัทเดียว (handoff §4 เคยค้างเรื่องนี้)

### B2. ดอกเบี้ยแบบช่วงงวด (tiered) 🔴
- เช่น 1.05%→12-18 งวด, 1.07%→24-30 งวด, 1.09%→32-42 งวด
- → **ตีความ:** `finance_company` ปัจจุบันมี `flat_rate_pct` เดียว ต้องเปลี่ยนเป็น **เรตต่อช่วงงวด** (ตาราง `finance_rate_tier`?) · หน้าขายเลือกจำนวนงวด → ได้เรต + คำนวณค่างวด auto

### B3. รอบติดตามลูกค้า (cadence)
- ลูกค้าอยากได้ **7 / 30 / 60 / 90 / 120 วัน** (spec เดิม/seed = 7/30/90/365/1095)
- → **ตีความ:** แก้ค่า `app_setting.follow_up_cadence` (ง่าย) · ยืนยันว่าตัด 365/1095 ทิ้งหรือแค่เพิ่ม 60/120

## C. หน้าจอ B2C (fold-in เข้า ticket หน้านั้น)

### สต๊อก/รุ่นรถ (→ FAM-1008, FAM-1009)
- เพิ่มรุ่น: มีทั้ง **ชื่อรุ่น + รหัสรุ่น** · **ใส่รูปรถ** (มี `model_photo` + bucket แล้ว) · **เอาปุ่ม "ขายคันนี้" ออก**
- อะไหล่/ของแถม: **แก้ราคาของแถมได้**

### รับรถเข้าสต๊อก (→ FAM-1007)
- สาขา → **บริษัท** + เพิ่มหัวข้อสาขา (ดู B1) · **แยกรุ่นรถกับสีออกจากกัน** · **ล็อกต้นทุน** · **ตัดราคาขายออก**

### ขายรถ (→ FAM-1011 + FAM-1019 finance + B2)
- เลือกคัน: **เอาราคาออก** (กันงง) · เช็คว่าแต่ละคันมี **ยี่ห้อ+รุ่น**
- เงินสด: ราคาตั้ง → เงินสด · เงินผ่อน: ราคาตั้ง → **ยอดกู้** · "ส่วนลด" relabel เป็น **"เงินดาวน์"**
- เลือกบริษัทไฟแนนซ์ → **ยอดกู้เปลี่ยนตามดอกเบี้ย auto** · สรุปดีล **auto-adjust ตลอด**
- เพิ่มช่องล่าง: **"ส่วนลด/โปรโมชั่น" + "ราคาสุทธิ"** (เงินดาวน์ − ส่วนลด = ราคาสุทธิ) · ของแถม **กดเพิ่มได้**
- **ลบ "เงินดาวน์ขั้นต่ำ"** · ปุ่ม **"ค้างจ่าย/ไม่ค้างจ่าย"** (ไว้ดู log)
- ฟอร์มลูกค้าในหน้าขาย: **ชื่อ, วันเกิด, เลขผู้เสียภาษี/บัตร ปชช. (ถ้ามี), ที่อยู่, เบอร์** → **แบ่ง section ให้ดี** (⚠️ PDPA: เลขบัตร ปชช. อ่อนไหว)
- สรุปดีล/ใบเสร็จ: **ปรับได้ว่าจะแสดงอะไร** (มีตัวอย่างรูป — รอไฟล์)
- **การเงินกดอนุมัติ** ก่อน (ดู A4)
- คำนวณค่างวด: **ปริ้นได้** + ใส่ข้อมูล sales (ผู้ดูแล/เบอร์) + **มี logo หัวกระดาษ**

### เอกสาร (→ FAM-1016)
- หลังบันทึกขาย: ออก **ใบเสร็จ + ใบกำกับภาษี (2 แบบ)** ให้ลูกค้า · รองรับ **auto-fill จากข้อมูลที่กรอก** และ **เขียนเอง manual**
- ใช้ **ราคาสุทธิ** · **ปริ้นได้**
- **ติดตาม statement การจ่าย**: ติ๊ก "ชำระแล้ว/ยังไม่ชำระ" + ปัญหา
- 🔴 **AI อ่าน/เข้าใจ PDF** (train model ให้รู้ว่าอะไรคืออะไร) — **รอไฟล์ PDF จากพี่เขา** → เชื่อมกับ Vercel AI SDK (FAM-E12)

### ลูกค้า & ดีล (→ FAM-E08)
- filter **รายการล่าสุดขึ้นบน** · **แจ้งเตือน email + บนเว็บ** ให้ sales
- ความคืบหน้า: **visual progress + คำอธิบายสั้นแต่ละสถานะ + signal ล่าช้า/ต้องแจ้ง + วันที่เล็ก ๆ**
- **เงินผ่อน flow:** ไฟแนนซ์ต้องผ่านก่อน → เปิดการขาย → ส่งมอบ → ลงทะเบียน
  - ไฟแนนซ์: กรอก บริษัทไฟแนนซ์/รุ่น/ราคา/ผ่านไหม/ถ้าไม่ผ่านเพราะอะไร
  - เงินสด: เปิดการขายแล้วจบเลย
- **"ลูกค้าเท" ตอนส่งมอบ** (เปลี่ยนใจ) — เขียนได้ว่าเทเรื่องอะไร เพราะอะไร · **ช่องหมายเหตุ**
- **ทะเบียน = ขั้นสุดท้าย** จบ sales แล้ว **ส่งต่อฝ่ายบริการ** (checklist manual) · **sales เห็น progress ฝ่ายบริการ**
- เพิ่มลูกค้า: หัวข้อ **สนใจแบบเงินสด/เงินผ่อน**
- follow-up 7/30/60/90/120 (ดู B3)

### Dashboard (→ FAM-1017)
- แสดง **ยอดค้างจ่ายเป็นตัวแดง เด่น ๆ**

### ศูนย์ซ่อม (→ FAM-E09)

### Design / Theming (→ ticket R1 ใหม่)

- ตัวอักษรใหญ่ขึ้น + minimal ขึ้น
- **เปลี่ยนสีเว็บ / dark mode / font ได้** (⚠️ ปัจจุบัน design เป็น light-only — dark mode เป็นงานใหญ่)
