## เป้าหมาย
กดปุ่มในแผงดีล → AI ร่างข้อความติดตามลูกค้า (ไทย) ตามจุดประสงค์ + context ของดีล → คัดลอกไปส่ง LINE/SMS

## ทำอะไร
- **`lib/ai/prompts/followup.ts`** (pure) — `followUpPrompt(input)` → system+user prompt · `sanitizeFollowUp` (ยุบช่องว่าง + cap 200) · `FOLLOWUP_PURPOSES` (5) + tests
  - system: พนักงานร้าน Yamaha, ไทยสุภาพ 2–4 ประโยค, **ห้ามแต่งข้อมูลที่ไม่ได้ให้ (ราคา/วันที่/โปร)**, ลงท้ายชื่อร้าน
- **`app/api/ai/draft-followup/route.ts`** — POST · `guardAi()` (401/503) → prompt → `claude-opus-5` (max 500) → `{ draft }` · รับเฉพาะ context ที่ลูกค้าเห็นได้ (ชื่อ/รุ่น/จุดประสงค์ — **ไม่มี money-field → ไม่มีเงินรั่ว**)
- **`components/ai/DraftFollowUp.tsx`** (client) — ปุ่ม ✨ → แผง: เลือกจุดประสงค์ + "ร่างด้วย AI" → textarea แก้ได้ + คัดลอก · error 401/503/502 แสดงสุภาพ
- wire ในแผงดีล (DealDrawer) — จุดประสงค์เริ่มต้นเดาจากขั้นดีล (`followUpSituation`: ส่งไฟแนนซ์→ติดตามไฟแนนซ์ ฯลฯ)
