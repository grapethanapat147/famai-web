# FAM-1014 · หน้าใบเสนอราคา (quote) — เทียบรถ/ไฟแนนซ์ให้ลูกค้า

**Epic:** FAM-E08 (ลูกค้าและการเงิน)
**สถานะ:** Done (รอเจ้าของ merge + ทดสอบเขียนจริงตอนล็อกอิน)
**สาขา:** `feat/quote-screen`

## เป้าหมาย
ออกใบเสนอราคาที่ **เทียบรถหลายคัน × ไฟแนนซ์ × หลายงวด** ให้ลูกค้า แล้วบันทึก/พิมพ์ได้

## ที่มา
- data model: `quotation` + `quotation_option` (docs/03 §2.9 "รถ 2 คัน × ไฟแนนซ์ 2 เจ้า × หลายงวด" · `terms` jsonb `[{months, monthly}]`)
- เมนู: roles admin/manager/sales · doc_no ผ่าน `next_doc_no(..., 'QUOTE', ปี พ.ศ.)`
- ค่างวดแบบดอกเบี้ยคงที่/เดือน (flat) เหมือนหน้าขาย

## ขอบเขต (in)
- Route `/quote` (SSR ผ่าน RLS): รายการใบเสนอราคา (เลขที่/ลูกค้า/วันที่/จำนวนคัน/หมดอายุ) + ค้นหา · ล่าสุดบน
- **ตัวสร้าง/เทียบ**: ลูกค้า (ชื่อ/เบอร์/ยืนราคาถึง) + 2 คัน (เลือกรุ่น → ราคาจาก retail · เงินดาวน์ · บริษัทไฟแนนซ์)
  - ตารางเทียบ side-by-side: ราคา/เงินดาวน์/ยอดจัด/ไฟแนนซ์ + **ค่างวด/เดือน ทุกจำนวนงวด**
- **บันทึก** → `createQuote` (quotation + quotation_option[] · doc_no · ด่านสิทธิ์ + RLS + cleanup best-effort)
- **พิมพ์** (window.print + `print:` utilities ซ่อน chrome, โชว์ตารางเทียบ)
- helper บริสุทธิ์ + tests: `flatMonthly`/`financedAmount`/`optionTerms`, `isExpired`/`filterQuotes`/`canManageQuote`
- `/dev/quote` preview + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา → FAM-1029)
- แม่แบบพิมพ์เต็ม (โลโก้หัวกระดาษ + ข้อมูลผู้ขาย/เบอร์ — R1 ขายรถ) · export PDF
- ดู/แก้ใบที่บันทึกแล้ว (ตอนนี้ list read-only + สร้างใหม่) · แปลงเป็นการขาย
- มากกว่า 2 คัน · ดอกเบี้ยแบบช่วงงวด (tiered, R1 B2)
