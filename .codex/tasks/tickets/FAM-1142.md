# FAM-1142 — popup ไม่มาอยู่กลางจอ (แก้ที่ Modal ให้แขวนใต้ body)

**สถานะ:** Done
**สาขา (git):** `fix/FAM-1142-modal-portal`
**ต้องรัน SQL:** ไม่ต้อง

## อาการที่เจอ
เกรพกดปุ่มกล้อง (แคปหน้าจอส่งซัพพอร์ต) บนแถบบน แล้ว popup ที่เด้งขึ้นมาไม่ได้อยู่กลางจอ

## สาเหตุ
`components/shell/TopBar.tsx` มีคลาส **`backdrop-blur`** บน `<header>`
ตาม CSS spec element ที่มี `transform` / `filter` / `backdrop-filter` จะกลายเป็น
**containing block ของลูกที่ `position: fixed`** → `inset-0` ของ Modal เลยไปยึดกับกล่องแถบบน
แทนที่จะยึดกับหน้าจอ popup จึงถูกบีบให้อยู่ในแถบบนสูง 56px

วัดจริงในเบราว์เซอร์: overlay ที่ `fixed inset-0`
- ancestor ปกติ → 280 × 895 ที่ top 0 (เต็มจอ ถูกต้อง)
- ancestor มี `backdrop-filter` → 280 × **56** ที่ top **549** (เท่ากล่องแถบบนเป๊ะ)

ตัว `Modal` เขียนถูกอยู่แล้ว (`fixed inset-0 flex … sm:items-center`) — ปัญหาอยู่ที่*ตำแหน่งใน DOM*

## ทำอะไรบ้าง
`components/ui/Modal.tsx` เรนเดอร์ผ่าน `createPortal(…, document.body)`
ชั้นซ้อนจึงแขวนใต้ `<body>` ตรง ๆ ไม่มี ancestor ไหนมาเปลี่ยน containing block ได้อีก
แก้ที่เดียวมีผลกับทุกโมดัลในระบบ (**18 ไฟล์เรียกใช้**) ไม่ใช่แค่ปุ่มแคปหน้าจอ

`SearchLauncher` ทำ portal อยู่แล้วตั้งแต่แรก — การแก้นี้ทำให้สองตัวบนแถบบนใช้แนวทางเดียวกัน

## ตรวจของข้างเคียงแล้ว
เทสต์ที่เขียนกันถอยหลังไปเจอไฟล์อื่นที่วาด overlay เต็มจออีก 4 ไฟล์ ตรวจทีละตัวแล้ว **ไม่โดนปัญหานี้**:
- `MobileNav` วาง overlay เป็น*พี่น้อง*ของ `<nav>` ที่เบลอ ไม่ใช่ลูก
- `CaptureButton` อยู่บนแถบโหมดลูกค้าซึ่งไม่มี blur/transform
- `Drawer` · `FilterBar` เรนเดอร์ในเนื้อหาหน้า ไม่มี ancestor ที่เบลอ

## เทสต์
`tests/modal-portal.test.ts` (4 เคส) — ไม่มี jsdom ในโปรเจกต์ จึงกันที่ระดับซอร์ส:
บังคับว่าสองตัวที่เปิดจากแถบบนต้องใช้ `createPortal` → `document.body` ·
ยืนยันว่าแถบบนยังมี `backdrop-blur` (เหตุผลยังเป็นจริง) ·
และ tripwire รายชื่อไฟล์ที่วาด overlay เต็มจอ — มีไฟล์ใหม่เมื่อไหร่เทสต์แดงให้มาตรวจว่าต้อง portal ไหม
