# FAM-1056 · E10 foundation — cron auth + LINE notify + aged-stock digest

**Epic:** FAM-E10 (Automation — Cron & LINE)
**สถานะ:** Done (branch feat/cron-aged-stock)
**ที่มา:** เกรพ — "ไปงานต่อไปได้เลย" (หลังปิด E11) · E10 ยังไม่เริ่ม

## เป้าหมาย
วาง foundation ของ cron + LINE แล้วส่ง job แรก: **แจ้งเตือนรถค้างสต๊อกเกินเกณฑ์** เข้า LINE ฝ่ายร้านทุกเช้า

## ทำอะไร
- **`lib/automation/cron-auth.ts`** (pure) — `isAuthorizedCron(header, secret)` เทียบ `Authorization: Bearer <CRON_SECRET>` แบบ constant-time · ไม่ตั้ง secret = ปฏิเสธ · + tests
- **`lib/line/message.ts`** (pure) — `agedStockDigest(aged, agingDays, dateLabel)` → ข้อความไทย (นับรวม + list 10 + "…และอีก N") · ไม่มีรถค้าง → null · + tests
- **`lib/line/notify.ts`** — `pushLineText` → LINE push API ถ้าตั้ง `LINE_CHANNEL_ACCESS_TOKEN` + `LINE_NOTIFY_TO` · ไม่ตั้ง = no-op (cron ไม่พัง)
- **`app/api/cron/aged-stock/route.ts`** — GET (dynamic) · auth → admin client อ่าน unit/branch/variant/aging_days → คำนวณรถค้าง (reuse `agedUnits`) → ส่ง LINE · `?preview=1` = ดูข้อความไม่ส่งจริง · **อ่านอย่างเดียว ไม่เขียน DB**
- **env**: เพิ่ม `CRON_SECRET` + `LINE_NOTIFY_TO` ใน .env.example
- **vercel.json**: cron `/api/cron/aged-stock` @ `0 2 * * *` (09:00 ไทย) · Vercel ใส่ Bearer CRON_SECRET ให้เอง

## Verify (dev)

- tsc + eslint + vitest (261) + build ผ่าน · route ขึ้นเป็น ƒ /api/cron/aged-stock
