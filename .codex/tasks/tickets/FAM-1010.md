# FAM-1010 · หน้าอะไหล่และของแถม (parts) + R1 แก้ราคาของแถม

**Epic:** FAM-E04 (บริการและอะไหล่)

**สาขา:** `feat/parts-screen`

## เป้าหมาย
รวม 3 หน้าเดิม (สต๊อกอะไหล่ · เบิก/ขายอะไหล่ · ของแถม) เป็นหน้าเดียว "อะไหล่และของแถม"
สิทธิ์**ไม่เท่ากันต่อแท็บ** (docs/04 §9h) — ด่านอยู่ที่ server ไม่ใช่แค่การวาดปุ่ม

## ที่มา
- docs/04 §9h (แท็บต้องเป็นด่าน สิทธิ์ต่อแท็บ ตัวนับแดง = อะไหล่ต่ำ + ของแถมต่ำ)
- data model: `part`, `part_movement`, `freebie` (RLS branch-scoped อยู่แล้ว migration 03/06)
- R1 (`.codex/specs/revision-1-client-feedback.md` §C): **แก้ราคาของแถมได้**

## สิทธิ์ต่อแท็บ (docs/04 §9h)
| แท็บ | ใครเข้าได้ |
|---|---|
| สต๊อกอะไหล่ | admin · manager · stock · tech · acct |
| เบิก/ขายอะไหล่ | admin · manager · stock · tech |
| ของแถม | admin · manager · stock · sales |

หลักการ: รวมหน้า **ไม่รวมสิทธิ์** · บัญชีเบิกของออกไม่ได้ · เซลล์เห็นต้นทุนอะไหล่ไม่ได้

## ขอบเขต (in)
- Route `/parts` (SSR): `allowedTabs` จาก role · โหลด `part`/`freebie` เฉพาะแท็บที่มีสิทธิ์ (เซลล์ไม่โหลด part)
- **ต้นทุนตัดฝั่งเซิร์ฟเวอร์** ด้วย `stripMoneyFields` (money: admin/manager/acct/hr เท่านั้น)
- แท็บเดียว → ไม่วาดแถบแท็บ (§9h ข้อ 2) · ตัวนับ badge = อะไหล่ต่ำ + ของแถมต่ำ (ข้อ 3)
- **สต๊อกอะไหล่**: ตาราง + ค้นหา + เฉพาะที่ต่ำ + ไฮไลต์ของต่ำ + ต้นทุน(guard)/ราคา
- **เบิก/ขายอะไหล่**: ฟอร์มตัดสต๊อก → `issuePart` (compare-and-swap กันติดลบ/แข่งกัน + log `part_movement`)
- **ของแถม**: รายการ + แก้ไข (ต้นทุน[money]/คงเหลือ/จุดสั่งซื้อ) → `updateFreebie` (R1)
- server action ทุกตัว**ตรวจสิทธิ์แท็บซ้ำ** (กันเรียกตรงข้ามสิทธิ์) + validate + RLS branch
- helper บริสุทธิ์ + tests: `allowedPartsTabs`, `canAccessPartsTab`, `isLowStock`, `partsBadgeCount`, `filterParts`
- `/dev/parts` preview (3 แท็บ + mock) + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา)
- แก้ข้อมูลหลักอะไหล่ (ต้นทุน/ราคา/จุดสั่งซื้อ) + รับอะไหล่เข้า (receive) → FAM-1026
- โอนอะไหล่ระหว่างสาขา (part_movement kind=transfer) → รวมกับหน้าโอนย้าย
- ผูกตัวนับ badge เข้ากับ sidebar counter (ตอนนี้แสดงบนหัวหน้าเท่านั้น)
