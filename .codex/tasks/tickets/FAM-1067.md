## เป้าหมาย
ถามภาษาไทยเรื่องสต๊อก/ยอดขาย → AI ตอบจากข้อมูลจริง **ผ่าน tool-use ที่เคารพ RLS + money-strip**

## 🔒 security (หัวใจ)
- AI ไม่แตะ DB ตรง — เรียกได้เฉพาะ **เครื่องมือแคบ ๆ** ที่ผมกำหนด (stock_summary / aged_units / sales_this_month)
- ทุก executor ดึงผ่าน `createServerSupabase()` = เซสชัน user จริง → **RLS แยกสาขาบังคับที่ DB** (branch-scoped user เห็นเฉพาะสาขาตัวเอง)
- คืน "ค่ารวม" ที่ **money-stripped** (มูลค่า/ยอดเงิน = null ถ้า role ไม่มีสิทธิ์ · reuse stockStats canSeeMoney) — AI ไม่เห็นตัวเลขต่อคัน
- แม้ prompt injection: RLS + null-money ที่ executor เป็นด่านสุดท้าย · system prompt สั่ง "ใช้เฉพาะข้อมูลจาก tool ห้ามแต่งตัวเลข"

## ทำอะไร
- **`lib/ai/tools.ts`** (server) — `ASSIST_TOOLS` (3 tool defs) + `runAssistTool(name,input,ctx)` executors (query via session, reuse stockStats/agedUnits)
- **`lib/ai/prompts/assist.ts`** (pure) — `assistSystemPrompt(canSeeMoney)` + tests
- **`app/api/ai/assist/route.ts`** — POST { question } · guardAi → **manual tool-use loop** (≤5 turns): create → tool_use → runAssistTool → feed back → end_turn → { answer }
- **`components/ai/AssistChat.tsx`** — ถามภาษาไทย + suggestion chips + คำตอบ · error สุภาพ
- **หน้า `/assist`** (real, `(app)/assist`) + **เมนู "ผู้ช่วย AI"** (group ภาพรวม, roles admin/manager; menu 21→22, bump menu.test) + `/dev/assist` harness
