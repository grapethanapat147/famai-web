## เป้าหมาย
วางรากฐาน theme engine — dark mode + ความหนาแน่น (per-user, localStorage) + ท่อฉีดสีเน้น global จาก `app_setting` (SSR, กันจอกระพริบ) · **ค่า default ไม่เปลี่ยนหน้าตาเดิม** · ยังไม่มีหน้าตั้งค่า (= FAM-1038)

## ทำอะไร (Done)
- `lib/theme/derive.ts` — `deriveAccent(hex,mode)` (hex↔HSL เฉด hover/deep/wash · fallback แดง) + `isValidHex` + tests
- `lib/theme/config.ts` (pure `parseThemeConfig`) + `lib/theme/settings.ts` (`getThemeConfig` server reader, resilient) — แยก pure/server-only ตามแบบ lib/settings + tests
- `app/globals.css` — `:root[data-theme=dark]` (สลับ neutral) + `:root[data-density=compact]` (font-size 15px lever)
- `components/theme/ThemeStyle.tsx` — server component ฉีด `<style html:root{…}>` สีเน้น (light เฉพาะ non-default · dark เสมอ)
- `components/theme/theme-init.ts` (no-flash blocking script) + `ThemeControls.tsx` (client, `useSyncExternalStore` — dark/density toggle, localStorage, data-attr, cross-tab)
- wire `app/layout.tsx` (script + ThemeStyle เป็นลูกแรก body · `suppressHydrationWarning` บน html) + `components/shell/TopBar.tsx` (`<ThemeControls/>`)
