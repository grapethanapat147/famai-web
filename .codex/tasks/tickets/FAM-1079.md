# FAM-1079 · หน้าแรกพาเข้าแอป + โหมดทดลอง login (ให้ลูกค้าลอง)

**Epic:** FAM-E03 (Auth) · **สถานะ:** Done (branch feat/demo-entry)
**ที่มา:** เกรพ (หลัง deploy จริง) — หน้าแรกเป็น dev placeholder ไม่ควรให้ลูกค้าเห็น · login บล็อกลูกค้าที่ยังไม่มีรหัส

## ทำอะไร
- **`app/page.tsx`** — เดิมเป็น dev placeholder (สถานะ Supabase ฯลฯ) → เปลี่ยนเป็น **redirect**: ล็อกอินแล้ว→`/dash` · ยังไม่→`/login` (ลูกค้าไม่เห็นข้อความ dev อีก)
- **`lib/auth/actions.ts` login** — เพิ่ม **โหมดทดลอง** (`DEMO_LOGIN=true`): ใส่อะไรก็ได้/ปล่อยว่าง → เข้าเป็นบัญชีจริง `DEMO_LOGIN_EMAIL`/`DEMO_LOGIN_PASSWORD` (env ฝั่ง server) → **ยังเห็นข้อมูลจริงผ่าน RLS** (ไม่ใช่หน้าว่าง) · ปิด = auth ปกติเป๊ะ
- **`components/auth/LoginForm.tsx`** — **จำ+โชว์** อีเมล/รหัสที่พิมพ์ (localStorage เครื่องนี้) เติมให้ครั้งต่อไป + ปุ่ม "แสดง/ซ่อน" รหัส + ป้ายโหมดทดลอง · ไม่บังคับกรอกในโหมดทดลอง
- **`app/login/page.tsx`** — ส่ง prop `demo` · **`.env.example`** — เพิ่ม DEMO_LOGIN\*

## ความปลอดภัย
- โหมดทดลอง **ดีฟอลต์ปิด** (`DEMO_LOGIN=false`) → auth จริงไม่กระทบ · เปิดเฉพาะช่วงโชว์ลูกค้า
- รหัสบัญชีทดลองอยู่ใน **env ฝั่ง server** (ไม่ commit · ไม่ NEXT_PUBLIC · ไม่หลุด client) · บัญชี = seed `admin@famai.local`
- **ต้องปิดก่อนเปิดใช้จริง** (ระบุใน .env.example)

## เปิดใช้ (เกรพตั้งที่ Vercel → Settings → Environment)
`DEMO_LOGIN=true` · `DEMO_LOGIN_EMAIL=admin@famai.local` · `DEMO_LOGIN_PASSWORD=<รหัส seed admin>` → redeploy

## Verify
- lint + typecheck + test + build เขียว
- โหมดปิด: login ปกติ (ต้องกรอกถูก) · `/` → /login
- โหมดเปิด (มี env): ใส่อะไรก็ได้ → เข้า /dash เห็นข้อมูลจริง · รีเฟรช login เห็นค่าที่จำไว้
