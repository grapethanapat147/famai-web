## เป้าหมาย (= epic "Done when")
ติดตั้ง SDK + endpoint ตัวอย่าง **ปิดไว้** พร้อมเปิดเมื่อเจ้าของสั่ง (ตั้งคีย์ + AI_ENABLED)

## ทำอะไร
- **dep ใหม่:** `@anthropic-ai/sdk` ^0.120 (official — ตามคำแนะนำ claude-api; ทางเลือก Vercel AI SDK รอเจ้าของยืนยัน)
- **`lib/ai/config.ts`** (pure) — `AI_MODEL="claude-opus-5"` · `isAiEnabled(env)` (ต้อง `AI_ENABLED=true` **และ** มีคีย์) · `withinDailyLimit` + tests
- **`lib/ai/client.ts`** (server-only) — `aiClient()` อ่าน `ANTHROPIC_API_KEY` ฝั่ง server เท่านั้น
- **`lib/ai/guard.ts`** (server) — `guardAi()`: ต้องล็อกอิน (401) + ฟีเจอร์เปิด (503) → คืน user (id/roleCodes) ให้ route ดึงข้อมูลผ่านชั้น user (RLS+money-strip)
- **`app/api/ai/ping/route.ts`** — POST ตัวอย่าง: guard → ยิงคำขอเล็กไป Claude ("ตอบ pong") · ปิดไว้ด้วย AI_ENABLED=false
- **.env.example:** `ANTHROPIC_API_KEY` (server-only, ห้าม commit) + `AI_ENABLED=false`

## Verify (dev, ยังไม่มีคีย์)
- POST /api/ai/ping ไม่ล็อกอิน → **401** "ยังไม่ได้ล็อกอิน" (auth gate) · GET → 405
- `isAiEnabled` เทสครบ (ต้อง flag+คีย์, ปิดเป็น default) · `withinDailyLimit` เทส
- tsc + eslint + vitest (285) + build ผ่าน · route = ƒ /api/ai/ping
- **503 (ปิดอยู่) + happy path (เปิด+คีย์) = เกรพเทสตอน login + ตั้งคีย์**

## ⚠️ ถึงเจ้าของ (ก่อนเปิดใช้จริง)
- ต้องตั้ง `ANTHROPIC_API_KEY` (server, ห้ามหลุด) + `AI_ENABLED=true` บน prod
- ยืนยัน: ฟีเจอร์แรก (แนะนำ ร่างข้อความติดตาม) · SDK (official/Vercel) · งบ/สิทธิ์ใช้ (ดู spec §6)
