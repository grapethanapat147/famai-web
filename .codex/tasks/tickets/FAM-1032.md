# FAM-1032 · หน้าลงเวลาและลา (hr)

**Epic:** FAM-E09 (บัญชีและพนักงาน)
**สถานะ:** Done (รอเจ้าของ merge + ทดสอบเขียนจริงตอนล็อกอิน)
**สาขา:** `feat/hr-screen`

## เป้าหมาย
Self-service: ลงเวลาเข้า/ออก + ขอลา + (ผู้มีสิทธิ์) อนุมัติใบลา — เติมฝั่งเขียนของกลุ่ม attendance (ต่อจาก attend)

## ที่มา
- data model: `attendance` (check_in/out, status, late_minutes) + `leave_request` (type, from/to, status, approved_by, reason) + `employee`
- RLS: attendance/leave scoped ตามสาขาของ employee · **อนุมัติ = perm `approve`** (admin/manager/hr)
- work_start จาก app_setting (คำนวณสาย) · R1 §ลงเวลา/ลา: หมายเหตุ+เหตุผล · ลิงก์ไปคนอนุมัติ · โควตา

## ขอบเขต (in)
- Route `/hr` (SSR ผ่าน RLS): employee ของฉัน + attendance วันนี้ + ใบลา (สาขา) + ชื่อผู้ลา
- **ลงเวลาวันนี้** (การ์ด): แสดงเวลาเข้า/ออก + ปุ่ม ลงเวลาเข้า/ออก → `clockIn`/`clockOut`
  - clockIn คำนวณ สาย/สถานะ จาก work_start (เวลาไทย) · clockOut คำนวณ work_minutes · กันลงซ้ำ
- **ใบลา**: แท็บ ของฉัน / รออนุมัติ(ผู้อนุมัติ) / ทั้งหมด · ปุ่ม "ขอลา" → modal → `requestLeave`
- **อนุมัติ** (perm approve): คลิกใบที่รออนุมัติ → drawer อนุมัติ/ไม่อนุมัติ (บังคับเหตุผลตอนปฏิเสธ) → `decideLeave` (CAS กันดำเนินซ้ำ)
- helper บริสุทธิ์ + tests (7 เคส): hhmm/lateMinutes/workMinutes + leaveDays/usedLeaveDays/filterLeaves/canApproveLeave
- เวลาแปลงเป็น Asia/Bangkok (Intl) ทั้ง client + action
- `/dev/hr` preview + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา)
- หลักฐาน geo/photo ตอนลงเวลา (migration 12 attendance_sites) + แนบใบรับรองแพทย์ (R1) · attendance_review (migration 11)
- **โควตาลา** จริง (ยังไม่มีแหล่งข้อมูลโควตา) → ตอนนี้มี `usedLeaveDays` โชว์ที่ใช้ไป · enforce เมื่อมี setting โควตา (R1 โควตาลาครบ→กดไม่อนุมัติ)
- แจ้งเตือนคนอนุมัติ (R1 ลิงก์ไปคนอนุมัติ)
