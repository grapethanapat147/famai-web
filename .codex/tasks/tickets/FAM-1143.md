# FAM-1143 — เปลี่ยนฟอนต์ของช่อง "รหัส" ให้อ่านง่ายและเหมือนกันทุกเครื่อง

**สถานะ:** Done
**สาขา (git):** `style/FAM-1143-mono-font`
**ต้องรัน SQL:** ไม่ต้อง

## ที่มา
เกรพไม่ชอบฟอนต์ของช่องเลขเครื่อง (`font-mono`) ขอฟอนต์ที่อ่านง่ายและคนทั่วไปคุ้นเคย

## ปัญหาที่ซ่อนอยู่
`--f-mono` เดิมคือ `ui-monospace, "SFMono-Regular", Menlo, monospace` — **ฟอนต์ระบบล้วน ไม่ได้ self-host**
แปลว่าพนักงานคนละเครื่องเห็นคนละฟอนต์: แมคเห็น SF Mono · วินโดวส์ตกไปที่ Consolas หรือ monospace ทั่วไป
ความชัดของ 0/O และ 1/l/I จึงไม่เท่ากันในแต่ละเครื่อง ทั้งที่ข้อมูลที่พิมพ์คือเลขเครื่อง/เลขถังที่ผิดตัวเดียวไม่ได้

## ทำอะไรบ้าง
ใช้ **Roboto Mono** ผ่าน `next/font/google` (self-host ตอน build เหมือน Inter/ไตรรงค์/อนุพันธ์ที่มีอยู่แล้ว
ไม่มี request ออก Google ตอนใช้งาน) แล้วให้ `--f-mono` ชี้มาที่ฟอนต์นี้ก่อน ค่อยตกไปฟอนต์ระบบถ้าโหลดไม่ทัน

เลือก Roboto Mono เพราะเป็นฟอนต์ที่คนคุ้นตาที่สุด (เห็นทั่วไปในผลิตภัณฑ์ Google/Android)
รูปทรงเปิดโล่ง อ่านง่ายที่ขนาดเล็ก และยังเป็น monospace อยู่ ตัวเลขจึงเรียงตรงคอลัมน์เหมือนเดิม

แก้ที่ตัวแปรกลางที่เดียว มีผลกับทุกที่ที่ใช้ `font-mono` (**24 ไฟล์**): เลขเครื่อง · เลขถัง ·
เลขที่เอกสาร · ทะเบียน · เบอร์โทร · รหัสเช็กสถานะลูกค้า · รหัสอะไหล่

## ถ้าอยากเปลี่ยนเป็นตัวอื่น
แก้บรรทัดเดียวใน `app/layout.tsx` (ชื่อฟอนต์) — ตัวที่พิจารณาไว้ด้วยกัน:
**IBM Plex Mono** (แยก 0 กับ O ชัดกว่านิดหนึ่ง) · **JetBrains Mono** (เลข 0 มีจุดตรงกลาง แยกชัดที่สุด แต่หน้าตาเป็นสายโค้ดดิ้ง)
