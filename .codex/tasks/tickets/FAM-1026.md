# FAM-1026 · แก้ข้อมูลหลักอะไหล่ + รับอะไหล่เข้า (parts master/receive)

**Epic:** FAM-E04 (บริการและอะไหล่)
**สถานะ:** Done (รอเจ้าของ merge + ทดสอบเขียนจริงตอนล็อกอิน)
**ขึ้นกับ:** FAM-1010 (แท็บสต๊อกอะไหล่ตอนนี้อ่านอย่างเดียว)

## เป้าหมาย
ให้ admin/manager/stock แก้ข้อมูลหลักอะไหล่ (ต้นทุน[money]/ราคา/จุดสั่งซื้อ) และ **รับอะไหล่เข้า** (เพิ่มสต๊อก + log movement)
ในแท็บ "สต๊อกอะไหล่"

## ขอบเขต
- ปุ่ม "เพิ่มอะไหล่" (สร้าง `part` ใหม่: code/name/cost/price/min_qty) — สิทธิ์ admin/manager/stock
- แก้ไขต่อรายการ: ต้นทุน (เฉพาะ money), ราคา, จุดสั่งซื้อ
- **รับเข้า**: บวก qty_on_hand + insert `part_movement` kind=receive (compare-and-swap หรือ RPC)
- server action **ตรวจสิทธิ์แท็บ stock** ซ้ำ + validate + RLS branch
- ต้นทุนไม่ส่งไป client ถ้าไม่มีสิทธิ์ (เหมือน FAM-1010)

## หมายเหตุ
ถ้าจะทำ receive/adjust ให้ atomic เป๊ะ พิจารณา RPC `adjust_part_stock()` (มิเรอร์ sell_unit/add_model)
— แต่ compare-and-swap แบบใน FAM-1010 ก็กันติดลบได้โดยไม่ต้องมี migration
