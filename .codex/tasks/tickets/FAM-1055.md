# FAM-1055 · E11 SEO — JSON-LD structured data (Product/Breadcrumb/ItemList)

**Epic:** FAM-E11 (Public Catalog & Status)
**สถานะ:** Done (branch feat/catalog-jsonld)
**ที่มา:** เกรพ — "ไปต่อ E11 ที่เหลือ" · ชิ้น SEO ที่ยังขาดหลัง OG/sitemap/robots เสร็จ

## เป้าหมาย
ฝัง structured data schema.org ให้หน้าสาธารณะ → Google rich result (ราคา/ความพร้อม/breadcrumb) เพิ่ม CTR

## ทำอะไร
- **`lib/catalog/jsonld.ts`** (pure) — `productJsonLd` (Product + Offer: price/THB/availability + brand Yamaha + image) · `breadcrumbJsonLd` (แคตตาล็อก→รุ่น) · `catalogItemListJsonLd` (รายการรุ่น) + tests (+10)
  - availability map: ready→InStock · low→LimitedAvailability · out→OutOfStock
  - retail null → ไม่ใส่ offers · image = รูปจริง (ถ้ามี) ไม่งั้น fallback เป็น og endpoint
- **`components/seo/JsonLd.tsx`** — ฝัง `<script type="application/ld+json">` (server component)
- **หน้ารายละเอียด** `/catalog/[code]`: Product + BreadcrumbList
- **หน้าแคตตาล็อก** `/catalog`: ItemList (ทุกรุ่น)
