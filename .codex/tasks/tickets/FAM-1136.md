# FAM-1136 — ของทดแทนสำหรับแพ็กฟรี: นโยบายรหัสผ่าน + สำรองข้อมูลด้วยมือ

**สถานะ:** Done
**สาขา (git):** `feature/FAM-1136-free-plan-guards`
**ต้องรัน SQL:** ไม่ต้อง

## ที่มา
fixlist ข้อ 25 ให้เปิด Leaked Password Protection + อัป Pro (เพื่อให้มี backup)
ตรวจเอกสาร Supabase แล้วพบว่า **Leaked Password Protection ใช้ได้เฉพาะแพ็ก Pro** และเจ้าของเลือก
**ยังไม่อัป Pro ตอนนี้** (จะเรียกเก็บลูกค้าตอนวางบิล) — สองช่องโหว่จึงเปิดค้างอยู่:
รหัสผ่านที่เดาง่าย และไม่มี backup เลย

ตั๋วนี้ปิดช่องโหว่ทั้งสองด้วยของที่ทำได้บนแพ็กฟรี **ไม่ใช่ตัวแทนถาวร** — อัป Pro แล้วยังต้องเปิดของจริง

## 1) นโยบายรหัสผ่านฝั่งแอป (`lib/auth/password.ts`)
บังคับตอนแอดมินสร้างบัญชีให้พนักงาน (ทางเดียวที่ระบบตั้งรหัสให้คนอื่น)
- ยาว **10 ตัวขึ้นไป** (เดิม 8) · ห้ามมีช่องว่าง
- ห้ามตัวเดียวซ้ำทั้งเส้น / เรียงต่อกัน (`12345678`, `abcdefgh`, รวมเรียงถอยหลัง)
- **ห้ามมีชื่อหรืออีเมลของผู้ใช้อยู่ข้างใน** — ตรวจก่อนกฎอื่นเพราะข้อความตรงประเด็นที่สุด
- ห้ามอยู่ในลิสต์รหัสยอดฮิต — เทียบแบบ**ตัดตัวเลข/สัญลักษณ์ท้ายออกด้วย** (`Password12!` → `password` ก็ติด)
- ต้องผสมอย่างน้อย 3 แบบจาก พิมพ์เล็ก/พิมพ์ใหญ่/ตัวเลข/สัญลักษณ์

ฟังก์ชันเดียวใช้ทั้ง 2 ฝั่ง: หน้าจอเตือนสดขณะพิมพ์ · `validateNewAccount` เป็นด่านจริงฝั่งเซิร์ฟเวอร์
ปุ่ม **สุ่ม** ย้ายมาอยู่ใน lib และการันตีว่าผ่านนโยบายเสมอ (เดิมสุ่มจาก ตัวอักษร+ตัวเลข อาจไม่ครบเงื่อนไข)
ตัดอักขระที่อ่านผิดง่าย (`l 1 I O 0`) ออก เพราะต้องอ่านรหัสให้พนักงานฟังทางโทรศัพท์

**ข้อจำกัดที่ต้องรู้:** ไม่ได้เทียบกับฐานรหัสที่รั่วจริงทั้งฐานแบบ HIBP — กันได้แค่รหัสที่เดาง่ายที่สุด

## 2) สำรองข้อมูลด้วยมือ (`scripts/backup.sh` · `npm run backup`)
แพ็กฟรีไม่มี backup อัตโนมัติเลย — ข้อมูลหาย = หายถาวร
สคริปต์อ่าน `DATABASE_URL` จาก `.env.local` → `pg_dump` → gzip → ตั้งชื่อตามวันเวลา → สรุปขนาด
+ **เตือนให้ก๊อปออกนอกเครื่อง** (เก็บในเครื่องอย่างเดียว เครื่องพังก็หายพร้อมกัน) + โชว์ไฟล์สำรองที่มีอยู่
ไม่มี `pg_dump` หรือ `DATABASE_URL` → บอกวิธีติดตั้ง/เติมค่า ไม่ใช่ error ดิบ
