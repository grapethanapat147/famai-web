## FAM-1008: Stock screen (สต๊อกรถ)

Status: Done
Priority: High
Epic: FAM-E05
Refs: Spec §9.3 · docs/03-data-model.md (motorcycle_unit) · .codex/specs/revision-1-client-feedback.md (C สต๊อก)

### Summary
หน้า `/stock` แสดงรถทุกคันตามสิทธิ์ (RLS เห็นเฉพาะสาขาตัวเอง เว้น allBranch) — ตัวกรอง + ค้นหา + ตารางกดได้→drawer รายคัน + money-strip (เซลล์/ไม่มีสิทธิ์ `money` ไม่เห็นต้นทุน) + แถบสีอายุสต๊อกตาม `aging_days`

### Acceptance Criteria
- `/stock` ดึง `motorcycle_unit` ผ่าน server client (RLS) + join รุ่น/สี/สาขา; ไม่ล็อกอิน → redirect /login (มีจาก FAM-1005)
- ตัวกรอง: สาขา (ถ้าเห็นหลายสาขา) · รุ่น · สถานะ (พร้อมขาย/จองแล้ว/กำลังโอนย้าย/ขายแล้ว) · ค้นหา (เลขเครื่องบางส่วน/รุ่น) + บรรทัดสรุป
- ตาราง per-unit (เดสก์ท็อป) → การ์ด (มือถือ, ไม่มี h-scroll) · กดแถว → drawer รายละเอียด (เลขเครื่อง/ถัง, วันที่รับ พ.ศ., อายุ, สถานะ, ต้นทุน, ราคาขาย)
- **money-strip**: `canSeeMoney()` + `stripMoneyFields(units, see, ['cost'])` — ต้นทุนไม่หลุดไป client ถ้าไม่มีสิทธิ์ (แสดง '—')
- อายุสต๊อก: ≤⅓ เกณฑ์ เขียว · ≤เกณฑ์ ส้ม · เกิน แดง (เกณฑ์จาก `app_setting.aging_days`)
- R1 fold-in (เบา): แสดงรูปรถถ้ามี · ไม่มีปุ่ม "ขายคันนี้" ในลิสต์
