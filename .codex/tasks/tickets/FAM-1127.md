## โครงสร้าง — ต่างจากขายปลีกตรงที่ 1 บิล = หลายคัน
| ตาราง | เก็บอะไร |
|---|---|
| `wholesale_company` | ร้านค้าปลายทาง + เลขผู้เสียภาษี/ที่อยู่ (ต้องใช้ตอนออกใบกำกับ) + เครดิตกี่วัน |
| `wholesale_order` | หัวบิล (เลขบิลชุด `WHOLESALE` แยกจาก RECEIPT/TAXINV) |
| `wholesale_order_line` | รายคัน — ราคาขายส่ง + **ต้นทุนแช่ ณ วันขาย** (กำไรย้อนหลังไม่ขยับตามราคาทุนปัจจุบัน) |

`unique(unit_id)` บน line — คันหนึ่งขายส่งซ้ำไม่ได้แม้โค้ดพลาด

## RPC `sell_wholesale` — atomic แบบเดียวกับ sell_unit
ล็อกทุกคันด้วย `for update` ก่อนตรวจ แล้วสร้างหัวบิล + รายคัน + ตัดสต๊อก ในทรานแซกชันเดียว
ด่านที่บังคับฝั่ง DB (ไม่ใช่แค่ฟอร์ม):
- ต้องมี role ขาย · รถต้องสถานะ `available` · ต้องมีสิทธิ์บริษัทของรถ
- **ทุกคันในบิลเดียวต้องเป็นบริษัทเดียวกัน** เพราะเลขบิลและเงินค้างรับผูกกับบริษัท
- ราคาต่อคันต้อง > 0

**ขายเชื่อ (เครดิต > 0) → ตั้งเงินค้างรับให้อัตโนมัติ** โผล่ในหน้ารอรับเงินเหมือนเคสไฟแนนซ์
(ต้องแก้ `receivable.sale_id` ให้ว่างได้ เพราะขายส่งมีบิลของตัวเอง ไม่ได้ผูกกับ `sale`)

## หน้าจอ
เมนูใหม่ **ขายส่ง (B2B)** (admin/manager/sales) มี 2 แท็บ
- **บิลขายส่ง** — ตาราง + ค้นเลขบิล/ร้านค้า/พนักงาน + กรองตั้งแต่วันที่
- **ร้านค้า** — เพิ่ม/แก้ไข (เฉพาะ admin/manager ตรงกับ RLS) · เตือนร้านที่ยังไม่มีเลขผู้เสียภาษี

**ฟอร์มเปิดบิล:** เลือกร้าน → ค้นรถจากสต๊อกพร้อมขาย → กดเพิ่มทีละคัน
**โชว์เลขเครื่อง/เลขถังของทุกคันตามบรีฟ** · ราคาตั้งต้นจากราคาปลีกแล้วแก้ได้ · สรุปยอด+กำไรสด
ขายเชื่อขึ้นป้ายบอกว่าจะตั้งเงินค้างรับให้ กี่วันครบกำหนด
