# FAM-1076 · สลิปเงินเดือนรายคน (PrintableEmployeePayslip)

**Epic:** FAM-E09 (Payroll) · **สถานะ:** Done (branch feat/payslip-doc)
**ที่มา:** เกรพ — "ทำสลิปเงินเดือนรายคนต่อเลย" · หน้า payroll เดิมพิมพ์ได้ทั้งตาราง (FAM-1073) แต่ยังไม่มีสลิป**รายคน**

## เป้าหมาย
ต่อยอดระบบเอกสาร (`.print-doc`/`.qdoc-*`) เพิ่มสลิปเงินเดือนพิมพ์ทีละคนจากหน้า payroll

## ทำอะไร
- **`components/payroll/PrintableEmployeePayslip.tsx`** (ใหม่) — หัวร้าน/สาขา (type `QuoteSeller`) · งวด (พ.ศ.) · ชื่อ+ตำแหน่ง · **รายรับ** (เงินเดือน, OT+ชั่วโมง, คอมมิชชั่น, รวมรายรับ) · **รายการหัก** (ประกันสังคม แสดงเป็นวงเล็บ) · **เงินได้สุทธิ** เน้น · ช่องเซ็นผู้จ่าย/ผู้รับ · หมายเหตุ (เอกสารลับ)
- **`lib/format.ts`** — เพิ่ม `formatThaiMonth('2567-08' → 'ส.ค. 2567')` (reuse TH_MONTHS)
- **PayrollView** — รับ prop `seller` · คอลัมน์ **"สลิป"** ปุ่มพิมพ์รายแถว (เฉพาะ canSeeMoney) → set คนที่เลือก + `window.print()` (rAF หลัง render) · render `<PrintableEmployeePayslip>` (ซ่อน) ของคนนั้น
- **`app/(app)/payroll/page.tsx`** — สร้าง `seller` จาก branch+company (มิเรอร์ deal/service) ส่งให้ PayrollView
- **`app/dev/payroll/page.tsx`** — seller ตัวอย่าง

## ความปลอดภัย
ตัวเลขถูก money-strip ที่ **server แล้ว** (`safeRows` = 0 เมื่อไม่มีสิทธิ์เห็นเงิน) · ปุ่มสลิปโชว์เฉพาะ `canSeeMoney` · คอลัมน์/ปุ่มเป็น `print:hidden` ไม่ติดไปบนกระดาษ
