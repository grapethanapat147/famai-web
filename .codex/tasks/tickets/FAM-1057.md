## เป้าหมาย
Cron job ที่ 2 (compliance สูง): เตือนทะเบียนที่ **ยังไม่ได้ป้าย + เลยกำหนด** (`due_at`) เข้า LINE ฝ่ายร้าน

## ทำอะไร (pattern เดียวกับ FAM-1056)
- **`lib/automation/clock.ts`** (pure, reusable) — `nowParts(now)` → ISO today + ป้ายไทย + tests
- **`lib/automation/registration.ts`** (pure) — `overdueRegistrations(rows, today)`: ยังไม่ป้าย + `due_at < today` → เรียงเกินนานสุด (คำนวณ daysOverdue ด้วย computeAgeDays) + tests
- **`registrationOverdueDigest`** ใน line/message.ts — "🟠 ทะเบียนเกินกำหนด — N ราย" + list (ลูกค้า · รุ่น · สาขา · เกิน X วัน · stage) + tests
- **`app/api/cron/registration-overdue/route.ts`** — auth → admin join registration→sale→customer + unit→variant + branch → overdue → LINE · `?preview=1` · read-only
- **vercel.json**: cron `0 3 * * *` (10:00 ไทย)
