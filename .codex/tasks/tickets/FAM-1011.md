### Summary

### รอบนี้ทำ (verifiable ผ่าน preview)
- `lib/sell/deal.ts` (pure) — `computeDeal`: ราคาสุทธิ = ราคาตั้ง−ส่วนลด · VAT (§6.3) · กำไร (§6.2, freebieIsCost) · ค่างวด flat (§6.4) + tests
- `components/sell/SellForm.tsx` — เลือกคัน (ไม่โชว์ราคาตอนเลือก, R1) · เงินสด/เงินผ่อน (chips) · ราคาตั้ง/ส่วนลด/เงินดาวน์ · ของแถมกดเพิ่มได้ (R1) · เลือกบริษัทไฟแนนซ์+งวด → ค่างวดสด · สรุปดีล auto-adjust · กำไร money-guard · เตือนค้าง/เตือน branch mismatch · ปุ่มขาย → **ConfirmDialog** (R1)
- `app/(app)/sell/page.tsx` (server, RLS) + `app/dev/sell/page.tsx` (preview)

### Deferred (ต้องมีของก่อน)
- **บันทึกการขายลง DB** — ต้องเพิ่ม `sell_unit()` RPC (transaction: insert sale + set unit sold + gen follow-up + กันขายซ้ำ unique) เป็น migration ใหม่ → apply เอง (handoff ⏳)
