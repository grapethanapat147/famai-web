## เป้าหมาย
หน้าอ้างอิงกระบวนการทำงานหลัก — แต่ละ process มีขั้นตอน + บทบาทผู้รับผิดชอบ + ลิงก์ไปหน้าที่ทำขั้นนั้น
พร้อมไฮไลต์ "งานของคุณ" ตามบทบาทผู้ใช้

## ที่มา
- เมนู: "ใครทำอะไรตอนไหน" · roles: ทุกบทบาท · ไม่มี DB (ข้อมูลคงที่ในโค้ด อ้าง role + เมนูจริง)

## ขอบเขต (in)
- Route `/flow`: getCurrentUser → ส่ง roleCodes ให้ FlowView (ไฮไลต์งานของบทบาท)
- 5 กระบวนการ: ขายมอเตอร์ไซค์ · ศูนย์ซ่อม · อะไหล่ · การเงิน · พนักงาน
- แต่ละกระบวนการ = การ์ด + ขั้นแนวตั้ง (เลข + เส้นเชื่อม): ชื่อขั้น · ป้ายบทบาท (ของฉันเน้นสี) · หมายเหตุ · ลิงก์ "ไปที่ <หน้า> →"
- toggle "เฉพาะงานของฉัน" (กรองเฉพาะกระบวนการที่เกี่ยวกับบทบาทฉัน) · legend บทบาท
- admin = เห็นทุกขั้นเป็นของตัวเอง
- helper บริสุทธิ์ + tests (6 เคส): **ตรวจ integrity ว่าทุก step.screen อ้างเมนูจริง + role ถูกต้อง** + stepInvolvesRole/flowInvolvesRole
- `/dev/flow` preview (สลับบทบาทดูไฮไลต์) + verify desktop/mobile ไม่มี h-scroll
