## ทำอะไร (ใช้ data เดิมล้วน ไม่แตะ query)
- **Header** — "ภาพรวม" (font-display) + ขอบเขตสาขา + "ข้อมูล ณ <วันไทย>" · chips ย้ายมาอยู่แถวเดียวกับ header
- **แถบพระเอก** — ยกมูลค่าสต๊อกรวมเป็นตัวเลขใหญ่ (สินทรัพย์ก้อนหลัก) + "N คันคงเหลือ · เฉลี่ย X/คัน" · คู่กับ "ขายเดือนนี้"
  - ไม่มีสิทธิ์ money → พระเอกสลับเป็น "สต๊อกคงเหลือ" (นับคัน) แทน `—` (Money strip)
- **กลุ่ม "ต้องจับตา"** — รวมเมตริกความเสี่ยง (ค้างเกิน N วัน · ทุนจมรถค้าง · ยอดค้างจ่าย-accent) ใต้ป้ายเดียว กวาดตาเจอง่าย
- **การ์ดกราฟ** — เพิ่มยอดรวม (N คัน) ที่หัวการ์ด
- asOf ส่งจาก server (กัน hydration) · dev header เดิมยุบ (ซ้ำกับ header ใหม่)
