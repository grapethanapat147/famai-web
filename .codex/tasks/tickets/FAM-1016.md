# FAM-1016 · หน้าโอนย้ายสาขา (transfer)

**Epic:** FAM-E03 (มอเตอร์ไซค์)
**สถานะ:** Done (รอเจ้าของ merge + apply migration 18 + ทดสอบเขียนจริงตอนล็อกอิน)
**สาขา:** `feat/transfer-screen`

## เป้าหมาย
ย้ายรถระหว่างสาขา (ในบริษัทเดียวกัน) — ขอโอน → กำลังโอน → รับเข้าสาขาปลายทาง
ปิดกลุ่ม "มอเตอร์ไซค์" (รับรถ → สต๊อก → โอนย้าย → ขาย)

## ที่มา
- data model: `unit_transfer` (status in_transit→received|cancelled) + `motorcycle_unit.status` in_transfer
- RLS §5: unit_transfer เห็นได้ทั้งสาขาต้นทางและปลายทาง
- R1 B1: **โอนข้ามบริษัทไม่ได้** ต้องเปิดการขาย · ในบริษัทเดียวกัน = ย้ายตามสาขาได้

## ขอบเขต (in)
- Route `/transfer` (SSR ผ่าน RLS): รายการโอน + join รถ/สาขา · KPI (กำลังโอน · รอรับสาขาฉัน)
- FilterBar: ค้นหา + ทิศ (ขาเข้า/ขาออก เทียบสาขาฉัน) + สถานะ
- ตาราง (มือถือ=การ์ด): รถ · ต้นทาง→ปลายทาง · สถานะ · วันที่ขอ · Drawer รายละเอียด
- **ขอโอนรถ** (modal): เลือกรถว่าง + สาขาปลายทาง + หมายเหตุ → `requestTransfer`
- **รับรถ** (ปลายทาง) → `receiveTransfer` · **ยกเลิก** (ต้นทาง) → `cancelTransfer`
- action ทุกตัว: ด่านสิทธิ์ + **same-company guard** (R1 B1) + CAS `motorcycle_unit.status` + revert เมื่อพลาด
  + ตรวจ "รับได้เฉพาะปลายทาง / ยกเลิกได้เฉพาะต้นทาง"
- helper บริสุทธิ์ + tests (8 เคส): directionOf/filterTransfers/transferCounts/sameCompany/canManageTransfer
- migration 18 (DRAFT) — ให้สาขาปลายทางเห็นรายละเอียดรถที่กำลังโอนเข้า (SELECT-only, ปลอดภัยต่อ isolation)
- `/dev/transfer` preview + verify desktop/mobile ไม่มี h-scroll

## ข้อจำกัดที่รู้ (แก้ด้วย migration 18)
ตอนโอน unit ยังอยู่สาขาต้นทาง → RLS เดิมซ่อนจากปลายทาง คนรับจึงไม่เห็นรุ่น/เลขเครื่องจนกว่าจะรับเข้า
migration 18 เพิ่ม SELECT policy ให้เห็น unit ที่อยู่ในรายการโอนที่เกี่ยวกับสาขาเรา (ก่อน apply → โชว์ fallback)

## ขอบเขต (out / ตามมา)
- log เหตุการณ์โอน (ใครขอ/ใครรับ) · แจ้งเตือนสาขาปลายทาง
- โอนข้ามบริษัท = ธุรกรรมขาย (ผูก company migration 16 + FAM-1011)
