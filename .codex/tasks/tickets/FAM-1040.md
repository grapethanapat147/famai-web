# FAM-1040 · ปุ่มแคปหน้าจอเฉพาะจุด (โหมดลูกค้า)

**Epic:** FAM-E13 (UI/ธีม track — งานที่ 4)
**สถานะ:** In Progress (branch feat/customer-capture)
**ที่มา:** วิชันเจ้าของ — "โหมดลูกค้าแค่ทำปุ่มให้สามารถปริ้นแบบแคปหน้าจอเฉพาะจุด"

## เป้าหมาย
ในโหมดลูกค้า (ซ่อนต้นทุน/กำไรอยู่แล้ว) เพิ่มปุ่ม "แคปเป็นรูป" → แคป card ที่กำหนดไว้ (ปลอดภัยต่อลูกค้า) เป็น PNG → เซฟ/แชร์ LINE ให้ลูกค้าได้ทันที

## ตัดสินใจ
- **แคปเฉพาะพื้นที่ที่ mark ไว้** (`data-capture="ชื่อ"`) ไม่ใช่ทั้งจอ → คุมได้ว่าอะไร export ให้ลูกค้าได้ (ตรงเจตนา "เฉพาะจุด" + กันหลุดข้อมูลในตัว) · เริ่มที่ตารางเทียบราคาใบเสนอราคา (CompareTable) เพิ่ม card อื่นทีหลังแค่ใส่ attribute
- **ไฟล์ = PNG** (ตรงคำว่า "แคป") ผ่าน `html-to-image` (lib เล็ก ~KB, MIT, zero-runtime-dep) — path เนทีฟ (SVG foreignObject) เปราะกับฟอนต์ไทย/รูป จึงเลือก lib · **เพิ่ม dependency ตัวแรกนอกเหนือ core → flag ใน PR ให้ merge = อนุมัติ**
- iOS/มือถือรองรับ (canvas ล้วน ไม่ใช้ getDisplayMedia ที่ iOS Safari ไม่รองรับ)

## ทำอะไร
- ปุ่มอยู่ในแถบโหมดลูกค้า (AppShell) — โผล่เฉพาะตอน customerMode
- สแกน `[data-capture]` ในหน้า → ไม่มี = ปุ่มไม่ขึ้น · มี ≥1 = กด → (หลายอัน = เลือก) → toPng → แชร์ (navigator.share ไฟล์ ถ้ามี → LINE) ไม่งั้นดาวน์โหลด `<ชื่อ>-<วันเวลา>.png`
- tag CompareTable ใน QuoteView = `data-capture="ใบเทียบราคา"`
- pure `lib/capture/filename.ts` (ชื่อไฟล์ปลอดภัย + timestamp) + unit test
- `/dev/capture` harness ยืนยันการสร้าง PNG แบบไม่ต้องล็อกอิน

## เจอตอน implement (สำคัญ)
- `toPng/toCanvas` ของ html-to-image **ค้าง**ในเบราว์เซอร์ (รอ image ภายในไม่จบ — วัดได้ 168 วินาที) → เลี่ยง
- แก้: ใช้แค่ `toSvg` (ส่วนยาก: clone DOM + inline computed style + ฝังฟอนต์ — 18ms) แล้ว **rasterize canvas เอง** (โหลด SVG เป็น Image + drawImage + toDataURL) → ทำงานทุกเบราว์เซอร์ + เร็ว
- แยกเป็น `lib/capture/image.ts` (`elementToPngDataUrl`) มี timeout กันค้าง · canvas ไม่ tainted (foreignObject → PNG ได้จริง)
