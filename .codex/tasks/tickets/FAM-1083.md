# FAM-1083 · เงา backdrop ค้นหาให้ครอบทั้งจอ

**Epic:** (fix) · **สถานะ:** In Progress (branch fix/search-overlay)
**ที่มา:** เกรพ — อยากให้ตอนเปิด search เงาดำครอบทั้งหน้า (รวม sidebar) เพื่อโฟกัสที่ช่องค้นหา

## ปัญหา
แผงค้นหาเรนเดอร์อยู่ใน `TopBar` ซึ่งมี `backdrop-blur` → สร้าง containing block ทำให้ `fixed inset-0` ของ overlay ไม่ครอบเต็ม viewport (sidebar/topbar ยังสว่าง)

## แก้
- `SearchLauncher` — เรนเดอร์ overlay+แผงผ่าน **`createPortal(document.body)`** → หลุดจาก containing block ของ TopBar → `fixed inset-0` ครอบทั้งจอจริง
- เงาเข้มขึ้น + เบลอเล็กน้อย (`bg-ink/60 backdrop-blur-[2px]`) + z สูง (z-[100]) → โฟกัสชัด
