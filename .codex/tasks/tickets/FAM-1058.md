Cron job ที่ 3 (repeat revenue): เตือนลูกค้าที่ **ถึงกำหนดเช็กระยะ** (service_reminder due แล้ว) เข้า LINE ฝ่ายร้าน · **cron ตัวแรกที่เขียน DB** (mark notified กันเตือนซ้ำ)

## ทำอะไร (pattern เดิม + write)
- **`lib/automation/service.ts`** (pure) — `dueReminders(rows, today)`: ยังไม่เคยเตือน + `due_date <= today` → เรียงกำหนดเร็วสุด + tests
- **`serviceReminderDigest`** ใน line/message.ts — "🔧 ถึงกำหนดเช็กระยะ N ราย" + list (ลูกค้า · รุ่น · เช็กระยะ X กม. · ครบ date) + tests
- **`app/api/cron/service-due/route.ts`** — auth → admin join service_reminder→customer + unit→variant → due → LINE
  - **idempotent**: ส่ง LINE **สำเร็จ** → UPDATE `notified_at=now()` เฉพาะ id ที่เตือน (กันซ้ำทุกวัน) · ส่งไม่ได้/ไม่ตั้งค่า → ไม่ mark (รอบหน้าลองใหม่)
  - `?preview=1` = ดูข้อความ ไม่ส่ง/ไม่เขียน
- **vercel.json**: cron `0 4 * * *` (11:00 ไทย)
