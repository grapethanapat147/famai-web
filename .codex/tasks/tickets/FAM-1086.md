# FAM-1086 · เชื่อมบัญชีกับข้อมูลพนักงาน (ปลดล็อกลงเวลา/ลา)

**Epic:** (feature) · **สถานะ:** Done (branch feature/FAM-1086-employee-selflink)
**ที่มา:** เกรพ — หน้า "ลงเวลาและลา" การ์ด "ลงเวลาวันนี้" ขึ้น "บัญชีนี้ยังไม่ผูกกับข้อมูลพนักงาน — ลงเวลาไม่ได้"

## รากปัญหา (ไม่ใช่โค้ดลงเวลาเสีย)
โค้ดลงเวลาเข้า/ออก + ขอลา ทำครบแล้ว แต่ **gate ด้วย employee ที่ผูก user_id = บัญชีปัจจุบัน**
ปรากฏว่า **ทั้งระบบไม่มีทางสร้าง `employee` เลย** (มีแต่ read; ไม่ seed; ไม่มี insert ที่ไหน)
→ ไม่มีบัญชีไหนลงเวลาได้ · payroll/hr ก็ไม่มีพนักงาน

## ทำ (ทางแก้ที่เล็ก + เดโมได้ทันที)
ปุ่ม **opt-in "เชื่อมบัญชีกับข้อมูลพนักงาน"** บนการ์ดตอนยังไม่ผูก → สร้าง `employee` ผูก user_id ปัจจุบัน
- branch = สาขาของผู้ใช้ (ไม่มี → สาขาแรก แคช FAM-1084) · position = จาก role · hired_at = วันนี้ · เงินเดือน/emp_code เว้นให้ HR เติม
- required แค่ branch_id · user_id unique = 1 พนักงาน/บัญชี (กันซ้ำ + จับ 23505)
- RLS employee ยอม insert สาขาที่ผู้ใช้เข้าถึง (admin allBranch ผ่าน)
- สำเร็จ → revalidate /hr → การ์ดเปลี่ยนเป็นลงเวลาเข้า/ออกได้ทันที
