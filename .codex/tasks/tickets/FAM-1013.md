# FAM-1013 · หน้าลูกค้าและดีล (deal) — ขาย·ไฟแนนซ์·ทะเบียน หน้าเดียว

**Epic:** FAM-E08 (ลูกค้าและการเงิน)
**สถานะ:** Done (รอเจ้าของ merge + ทดสอบเขียนจริงตอนล็อกอิน)
**สาขา:** `feat/deal-screen`

## เป้าหมาย
รวมงานลูกค้า/ดีลเป็นหน้าเดียว (ขาย·ไฟแนนซ์·ทะเบียน) — เห็นความคืบหน้าเป็น**แถบเลขขั้น**
และเลื่อนขั้นจากหน้าเดียว ไม่ต้องข้ามหน้า

## ที่มา (สำคัญ)
- docs/04 §9f (แถบเลขขั้น ไม่ใช่คัมบัง) + §9g (**ขั้นคำนวณจากระเบียนจริง ไม่เก็บฟิลด์ที่สาม** · เงินสด 4 ขั้น เงินผ่อน 6 ขั้น · โชว์เฉพาะปุ่มขั้นปัจจุบัน "ไป: … →")
- data model: `registration.stage` = ไปป์ไลน์ดีล (ขายแล้ว→ส่งไฟแนนซ์→อนุมัติ→รอทะเบียน→ป้ายขาว→ส่งมอบแล้ว) · `finance_case` = ข้อมูลสินเชื่อ (ปฏิเสธ=ตกราง)
- R1 §ลูกค้า&ดีล: **ล่าสุดขึ้นบน** · visual progress + วันที่เล็ก ๆ + signal ตกราง · เงินสดจบเร็ว/เงินผ่อนไฟแนนซ์ก่อน

## ขอบเขต (in)
- Route `/deal` (SSR ผ่าน RLS): ดีล = การขายที่ยังไม่ยกเลิก + join ทะเบียน/สินเชื่อ/ลูกค้า/รถ · เรียงล่าสุดบน (R1)
- **ขั้นคำนวณจากระเบียน** (registration.stage + finance_case) — ไม่มีฟิลด์ deal.stage
- สรุปตามขั้น (นับ กดกรอง) + FilterBar: ค้นหา + ยังไม่ส่งมอบ
- ตาราง (มือถือ=การ์ด): ลูกค้า/รถ · ชำระ · ขั้น (ตกราง=ไฟแนนซ์ปฏิเสธ) · วันที่ขาย · ยอดสุทธิ
- Drawer: **StepBar** (track ตามวิธีชำระ · ขั้นปัจจุบัน · ตกราง=วงแดงกลวง) · รายละเอียด · กล่องสินเชื่อ (บริษัท/สถานะ/ยอด/เหตุผลปฏิเสธ)
- **ต้องทำต่อ**: ปุ่มเดียวของขั้นปัจจุบัน "ไป: <ถัดไป> →" → `advanceRegistration`
  (ด่านสิทธิ์ + **วิธีชำระอ่านจากการขายจริง** ไม่เชื่อ client + อนุญาตแค่ขั้นถัดไปเดียว + compare-and-swap + ตั้งวันที่ตามขั้น)
- helper บริสุทธิ์ + tests (9 เคส): dealTrack/regNext/stageIndex/stageTimestampField, filterDeals/stageCounts/isOffTrack/canManageDeal
- `StepBar` UI component (docs/04 §9f) · `/dev/deal` preview + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา → FAM-1028)
- งานสินเชื่อเต็ม: `finance_case` เลื่อนสถานะ (ธ.อนุมัติ/ปฏิเสธ) + การเงินกดอนุมัติ (R1 A4) + ยื่นใหม่หลังตกราง
