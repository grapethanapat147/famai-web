**สถานะ:** Done

**ต้องรัน SQL:** ใช่ — `supabase/migrations/20260902100000_30_sale_downstream_records.sql`

## ปัญหา
`sell_unit` สร้าง ลูกค้า + บิลขาย + งานทะเบียน + เคสไฟแนนซ์ + งานติดตาม
แต่ **ไม่เคยสร้าง 3 อย่าง** ที่หน้าจอปลายทางรออ่านอยู่ ทำให้ของที่สร้างไว้แล้วว่างตลอดกาล

| ข้อ | ขาดอะไร | ผลที่เกิด |
|---|---|---|
| 01 | `receivable` | หน้ารอรับเงิน + การ์ดยอดค้างว่างเสมอ ไม่รู้ไฟแนนซ์ค้างจ่ายเท่าไหร่ |
| 02 | `service_reminder` | cron เตือนเช็กระยะอ่านเจอแต่ตารางเปล่า ไม่เคยเตือนสักครั้ง |
| 03 | `registration.due_at` | cron เตือนทะเบียนใกล้ครบกำหนดไม่เคยทำงาน ลูกค้าปล่อยทะเบียนขาดได้ |

## ทำอะไรบ้าง
**migration 30** — `sell_unit` เพิ่ม 3 อย่าง (ยังอยู่ใน transaction เดียวกัน ขายล้ม = ไม่มีเศษข้อมูลค้าง)
- `registration.due_at = วันขาย + reg_days`
- ขายเงินผ่อนและยอดจัด > 0 → `receivable` (kind `finance`, ผู้จ่าย = ไฟแนนซ์, ครบกำหนด = วันขาย + `ar_due_days`)
- `service_reminder` รอบแรก = ระยะต่ำสุดใน `service_km` ครบกำหนด = วันขาย + `service_first_days`

**RPC ใหม่ `next_service_reminder(job_id)`** — ปิดใบงานซ่อม (สถานะ → เสร็จ) แล้วตั้งรอบถัดไปให้เอง
เลือกระยะแรกใน `service_km` ที่มากกว่าเลขไมล์ปัจจุบัน · เลยระยะสุดท้าย/รถนอก = ไม่ตั้ง
เรียกจาก `advanceStatus` แบบ best-effort (ตั้งเตือนไม่ได้ ไม่ทำให้ปิดใบงานล้ม)

**ค่าตั้งใหม่ 2 ตัว** (ไม่ฝังตัวเลขในโค้ด) โผล่ในหน้าตั้งค่าระบบทันที
- `ar_due_days` = 30 — "ไฟแนนซ์ต้องโอนภายใน"
- `service_first_days` = 30 — "นัดเช็กระยะภายใน"
