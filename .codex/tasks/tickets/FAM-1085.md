# FAM-1085 · หน้า /recv รับรถเข้าสต๊อกทีละคัน

**Epic:** (feature) · **สถานะ:** In Progress (branch feature/FAM-1085-recv)
**ที่มา:** เกรพ — `/recv` เป็นเมนูเดียวที่ยังไม่ได้สร้าง (ตกไปที่ placeholder `[screen]`); หน้า stock ตอนว่างก็มีปุ่มชี้มา `/recv`

## ขอบเขต
ฟอร์มรับรถเข้าสต๊อก **ทีละคัน** (คู่กับ `/imp` ที่นำเข้าจากไฟล์ยามาฮ่าทีละหลายคัน)
- insert 1 แถวใน `motorcycle_unit` · RLS บังคับสาขา · เลขเครื่อง/เลขตัวถังห้ามซ้ำ
- สิทธิ์: admin / manager / stock (ตรงกับ `/imp`)
- ต้นทุน (cost/cost_vat) เป็นข้อมูลเงิน → โชว์เฉพาะผู้มีสิทธิ์ `money`; ไม่มีสิทธิ์ → เว้นไว้ (0 = รอกำหนดภายหลัง)

## ฟิลด์
สาขา (default สาขาผู้ใช้) · รุ่น (variant) · สี (กรองตามรุ่น) · ประเภท (รถใหม่/มือสอง) ·
เลขเครื่อง* · เลขตัวถัง* (เตือนถ้าไม่ครบ 17) · วันที่รับ (default วันนี้) ·
ราคาขาย/retail (ไม่บังคับ · ว่าง = รอกำหนด) · ต้นทุน + VAT ต้นทุน (money-gated, VAT auto = cost×vat%)
- sku = variant.code + color_code (คิดฝั่ง server จาก id ที่เชื่อถือได้) · status = available

## ไฟล์
- `lib/recv/recv.ts` — pure: `canReceiveStock`, `validateRecvInput`, `deriveSku`, `computeCostVat` + types
- `app/(app)/recv/page.tsx` — เตรียมข้อมูล (variants+colors, สาขาแคช FAM-1084, vat) + gate
- `app/(app)/recv/actions.ts` — `receiveUnit`: gate + validate + resolve variant/สี + เช็คซ้ำ + insert + revalidate /stock
- `components/recv/RecvForm.tsx` — ฟอร์ม (mirror SellForm) + confirm + reset เลขเครื่อง/ตัวถังหลังบันทึก (รับต่อเนื่องเร็ว)
- `app/dev/recv/page.tsx` — preview (sample data + mock action) สำหรับ verify
- `tests/recv.test.ts` — pure logic
