## ทำ ✅ (branch feature/FAM-1107-flow-bridges) — ไม่ต้อง migration
1. **ขายเสร็จ → ลิงก์ไปดีลทันที** — SellForm เก็บชื่อลูกค้าก่อนรีเซ็ต แล้วโชว์ "ไปดีลของ {ชื่อ} →" (/deal?q=) ข้าง badge สำเร็จ (เดิม saleId ถูกทิ้ง ผู้ใช้ต้องไปค้นเอง — รอยต่อกลาง flow หลัก)
2. **กันเลื่อนขั้นข้ามการบันทึกเลขทะเบียน** — advanceRegistration (หน้าดีล) ปฏิเสธการเลื่อนเข้า "ป้ายขาว" เมื่อ plate_no ยังว่าง (pure `advanceBlockReason` + test) เพราะ recordPlateReceived เป็นผู้บันทึกเลขทะเบียนทางเดียวและรับเฉพาะขั้นรอทะเบียน — เดิมข้ามได้แล้วเลขทะเบียนหายจากระบบ
3. **DealDrawer ชี้ทางไปหน้า งานทะเบียน** — ขั้นรอทะเบียน/ป้ายขาว มีลิงก์ "บันทึก…ที่หน้า งานทะเบียน →"
4. **คิวทะเบียน → ดูดีลได้** — ชื่อลูกค้าในตาราง /registration เป็นลิงก์ /deal?q={ชื่อ}
5. **รับรถแล้ว → ดูในสต๊อก** — recv action คืน unitId (insert…select) + ลิงก์ "ดูในสต๊อก →" (/stock?unit=) โดยไม่แตะพฤติกรรมรับต่อเนื่อง
6. **กันตัวเลขติดลบในการขาย** — pure `validateSellPricing` (ส่วนลด/เงินดาวน์ ≥ 0, ส่วนลด ≤ ราคาตั้ง) ใช้ใน sell action + MoneyStepInput ใส่ min=0 + clamp ตอนพิมพ์ (เดิม -5000 ผ่านได้ ทำ net/กำไร/ยอดจัดไฟแนนซ์เพี้ยนถาวร)
