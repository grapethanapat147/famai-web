## 1) ไอคอนปรับขนาดตัวอักษร: ขีดสามเส้น → **Aa**
ปุ่มปรับความหนาแน่น (`data-density`) ใช้ไอคอนขีดสามเส้น ซึ่งคนอ่านว่า "เมนู" ไม่ใช่ "ปรับขนาด"
เปลี่ยนเป็นตัวอักษร **A ใหญ่ + a เล็ก** ซึ่งเป็นสัญลักษณ์สากลของการปรับขนาดตัวอักษร
(โหมดกระชับหด `font-size` ของ root จาก 16px เหลือ 15px → ทั้ง spacing และตัวอักษรเล็กลงตาม จึงสื่อตรงกับ Aa จริง ๆ)

## 2) การ์ดแยกจากพื้นหลังยาก → ใส่เส้นขอบบางเข้าไปใน "เงา"
การ์ดเป็นสีขาวล้วนบนพื้น `#fafaf8` และเงาเดิมจางมาก (`0 1px 2px` ที่ 6%) มองแล้วแยกก้อนไม่ออก

แก้ที่ **โทเคน `--sh-sm` ตัวเดียว** โดยผสมเส้นขอบ 1px เข้าไปในเงา:
`0 0 0 1px rgba(22,24,29,0.09), 0 1px 3px rgba(22,24,29,0.07)`

ทำแบบนี้เพราะโทเคนนี้ถูกใช้ **57 จุดใน 33 ไฟล์** — ไล่เติม `border` ทีละที่จะพลาดแน่นอน
และ `box-shadow` ไม่กินพื้นที่ layout จึงไม่ดันของอย่างการเติม border จริง · ทำให้ธีมมืดด้วย (ขอบขาว 9%)

## 3) ปุ่ม "ขายรถ" ลอย → เป็น 1 ใน 6 ไอคอนบนแถบล่าง
เดิมแถบล่างมี 4 เมนู + ช่องว่าง + "อื่นๆ" แล้วมีปุ่มกลมสีแดงลอยทับเนื้อหาอยู่ตรงกลาง
ปุ่มลอยนี้บังการ์ดด้านหลัง (เห็นชัดในภาพที่เกรพส่งมา — ทับยอดขายวันนี้อยู่)

เปลี่ยนเป็น **5 เมนู + "อื่นๆ" = 6 ช่องเท่ากัน** โดยใส่ `sell` เข้าไปในลำดับความสำคัญของแถบล่าง
ตัดปุ่มลอยกับช่องว่างที่เว้นไว้ให้มันออก และเลิกส่ง prop `canSell` ทั้งสาย (layout → AppShell → MobileNav)

วัดจริงที่ 375px: ช่องละ **63px** · ป้ายที่ยังตัดเหลือแค่ "อะไหล่และของแถม" ซึ่งตัดอยู่แล้วตั้งแต่ก่อนแก้
ปรับป้ายเป็น `text-[10px]` + `w-full truncate text-center` ให้ "ลูกค้าและดีล" แสดงครบ
