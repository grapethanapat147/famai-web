## 1) a11y sweep
ของเดิมดีอยู่แล้ว (focus ring ทั้งแอปที่ globals.css:101, Drawer/Modal มี role=dialog/aria-modal/aria-label/Esc, ปุ่มไอคอนมี aria-label) → เติมช่องที่ขาด:
- **Skip-to-content link** ใน `AppShell` (`ข้ามไปเนื้อหาหลัก` → `#main`) + `<main id="main" tabIndex={-1}>` — คีย์บอร์ดข้าม nav ได้
- **ตั้งชื่อ form control ที่มีแต่ placeholder**: `aria-label` ให้ช่องค้นหา 12 หน้า + select กรอง 4 ตัว (สาขา/รุ่น/หมวด/บทบาท) — ปิดช่องว่าง WCAG 4.1.2

## 2) print CSS เอกสาร
**บั๊กเดิม:** `@media print` ซ่อน `body *` แล้วโชว์เฉพาะ `.print-doc` → หน้า **รายงาน/เงินเดือน** ที่กด "พิมพ์" (ไม่มี .print-doc) พิมพ์ออกมา **ว่างเปล่า** (ทั้งที่ ReportView/PayrollView ใส่ `print:hidden` chrome ไว้แล้ว แต่ถูก rule รวมกลบ)
- แก้ `@media print` ใช้ **`:has(.print-doc)`** → โหมดเอกสารเดี่ยว (ใบเสนอราคา) ทำงานเหมือนเดิม · หน้าอื่นพิมพ์เนื้อหาปกติ
- ใส่ `print:hidden` ให้ chrome: Sidebar / TopBar / MobileNav (ปุ่มขายลอย+แถบล่าง) / แถบโหมดลูกค้า
