# FAM-1046 · UI polish — เจาะหน้าขาย (SellForm)

**Epic:** FAM-E13 (UI/ธีม track — polish รอบ 5)
**สถานะ:** Done (branch feat/sell-polish)
**ที่มา:** เกรพ — "ไปเจาะหน้าขายต่อ"

## ปัญหาเดิม
- คันที่เลือกเห็นแค่ใน dropdown (ตัดข้อความ) — คนขายไม่เห็นชัดว่าเลือกคันไหน (เสี่ยงผิดคัน)
- สรุปดีลเป็นแถวเท่ากันหมด — เลขที่สำคัญ (ราคาสุทธิ/ค่างวด) ไม่เด่น
- ชิปของแถมเขียนเอง (ไม่ตรงกับ Chips ที่ขัดแล้ว) + ไม่บอกราคา

## ทำอะไร (logic/computeDeal เดิม ไม่แตะ)
- **การ์ดคันที่เลือก** — โผล่เมื่อเลือกคัน: รุ่น·สี (เด่น) + เลขเครื่อง(mono) + สาขา + badge อายุ (เขียว/เหลืองถ้าค้าง) · รวมคำเตือน (ค้างสต๊อก/สาขาไม่ตรง) ไว้ในการ์ดเดียว → คนขายเห็นรถ+สถานะ+คำแนะนำที่เดียว
- **สรุปดีล hero** — ยก "ราคาสุทธิ" เป็นตัวเลขใหญ่ + (ผ่อน) "ค่างวด/เดือน" ใหญ่ × N งวด · ที่เหลือเป็นแถวย่อย · **empty state** เมื่อยังไม่เลือกคัน ("เลือกคันเพื่อดูสรุปดีล")
- **ชิปของแถม** — สไตล์เดียวกับ Chips (hover ขอบ + active:scale) + โชว์ราคา ฿ ต่อชิ้น (เมื่อ canSeeMoney; ของแถมกระทบกำไรถ้า freebieIsCost)
