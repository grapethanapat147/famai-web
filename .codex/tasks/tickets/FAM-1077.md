# FAM-1077 · ใบกำกับภาษี (PrintableTaxInvoice)

**Epic:** FAM-E06 (Documents) · **สถานะ:** In Progress (branch feat/tax-invoice)
**ที่มา:** เกรพ — "ทำใบกำกับภาษีต่อเลย" · เอกสารทางกฎหมาย ต่างจาก 4 ใบก่อน

## เซอร์ไพรส์: โครงสร้างมีอยู่แล้วเกือบครบ (ไม่ต้องแก้ schema)
- `customer` มี `address` + `tax_id` แล้ว (ข้อมูลผู้ซื้อ)
- `next_doc_no(branch,'TAXINV',year)` + `sell_unit` RPC **ออกเลขที่ใบกำกับภาษีตอนขายอยู่แล้ว** → เก็บใน `sale.doc_no`
- `vat_pct` เป็น setting (default 7) · สูตร VAT ใน `lib/sell/deal.ts` (ราคาสุทธิ = รวม VAT แล้ว)

## ทำอะไร (ส่วนใหญ่คือต่อสายข้อมูลที่มี)
- **`lib/deal/deals.ts`** — เพิ่มฟิลด์ Deal: `docNo`, `customerAddress`, `customerTaxId` + ฟังก์ชันบริสุทธิ์ **`vatBreakdown(net, vatPct)`** (แยกมูลค่าก่อนภาษี + VAT) + เทส
- **`components/deal/PrintableTaxInvoice.tsx`** (ใหม่) — หัวร้าน + เลขภาษีผู้ขาย · **เลขที่ใบกำกับภาษี** (จาก doc_no) + วันที่ · ผู้ซื้อ (ชื่อ + ที่อยู่ + เลขภาษี ถ้ามี — ปรับตามข้อมูล) · ตารางรายการ + **มูลค่าก่อนภาษี / VAT 7% / รวมทั้งสิ้น** · เซ็นผู้รับเงิน/ผู้ซื้อ
- **DealView/DealDrawer** — prop `vatPct` · **2 ปุ่มพิมพ์**: "พิมพ์ใบขาย" + "พิมพ์ใบกำกับภาษี" (โชว์เมื่อมี doc_no) · state `printDoc` ("sale"|"tax") → render ทีละเอกสาร (กัน `.print-doc` ซ้อน) แล้ว window.print()
- **`app/(app)/deal/page.tsx`** — ดึง `sale.doc_no` + `customer.address/tax_id` + `getSetting("vat_pct")` ส่งเข้า Deal/DealView
- **`app/dev/deal/page.tsx`** — mock docNo/ที่อยู่/เลขภาษี (บางดีลมีเต็ม บางดีลชื่ออย่างเดียว บางดีลไม่มี doc_no)

## Verify

- /dev/deal เปิดดีลที่มี doc_no → ปุ่ม "พิมพ์ใบกำกับภาษี" · `.print-doc` แยก VAT ถูก (มูลค่า+VAT=รวม)
- ดีลไม่มี doc_no (เก่า) → ไม่มีปุ่มใบกำกับภาษี
