# FAM-1028 · งานสินเชื่อเต็ม + เปิดดีล/ลูกค้าเท (deal follow-ups)

**Epic:** FAM-E08 (ลูกค้าและการเงิน)
**สถานะ:** Backlog
**ขึ้นกับ:** FAM-1013 (หน้าดีลตอนนี้ list + เลื่อนขั้นทะเบียน · สินเชื่อยัง read-only)

## เป้าหมาย
เติมส่วนที่ FAM-1013 กันไว้ให้ครบวงจรดีล

## ขอบเขต
- **งานสินเชื่อ (finance_case)**: เลื่อนสถานะ (ส่งเรื่อง→ยื่นเอกสาร→รอผล→อนุมัติแล้ว|ปฏิเสธ) + `finance_case_event` log
  - ตกราง (ปฏิเสธ) → **ยื่นใหม่** (บริษัทใหม่) หรือ **ยกเลิกดีล**
  - **การเงินกดอนุมัติ** (R1 A4: `sale.payment_confirmed_by`) ก่อนเดินต่อ
  - ดอกเบี้ยแบบช่วงงวด (R1 B2 · `finance_company.rate_tiers`)
- **เปิดดีลใหม่** จากหน้านี้ (สร้าง sale + registration อัตโนมัติ — §9f: ทุกการขายสร้างงานทะเบียน)
- **ลูกค้าเท** (R1): void ดีล + เหตุผล/หมายเหตุ ตอนส่งมอบ
- **ส่งต่อฝ่ายบริการ** เมื่อจบ (R1: sales เห็น progress ฝ่ายบริการ)
- แจ้งเตือน email + บนเว็บ ให้ sales (R1) · follow-up 7/30/60/90/120 (R1 B3)

## หมายเหตุ
finance_case เลื่อนสถานะ + อัปเดต registration.stage ให้สอดคล้อง = หลายตาราง → พิจารณา RPC
หรือ compare-and-swap แบบเดียวกับ FAM-1010/1012/1013
