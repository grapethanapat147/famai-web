## FAM-1003: Core UI components

Status: Backlog
Priority: High
Epic: FAM-E02
Refs: docs/04-design-system.md §11.3 · index.html (v1.15) · Spec §11.3-11.4

### Summary
คอมโพเนนต์ที่ใช้ซ้ำทุกหน้า (จาก §11.3): การ์ด KPI, แถบตัวกรอง (+สรุปว่าดูอะไรอยู่), ตารางกดได้ → แผงรายละเอียดสไลด์จากขวา (ปิดด้วยปุ่ม/พื้นหลัง/Esc), หน้าต่างซ้อน (modal), ป้ายสถานะ 5 แบบ (ดี/เตือน/แย่/ข้อมูล/ปิด), ป้ายที่มาข้อมูล (`ข้อมูลจริง`/`ข้อมูลสมมุติ`), บนมือถือ: ตาราง→การ์ด, แท็บ→ชิป, ตัวกรอง→แผ่นล่าง (v1.4)

### Acceptance Criteria
- แต่ละคอมโพเนนต์ typed + มี stories/ตัวอย่าง + test พฤติกรรม (Esc ปิด drawer, ป้ายแยกด้วยตาเปล่า)
- ยึดกฎ §11.4: ทุกตัวเลขบอกที่มาได้, preview ก่อนบันทึก, คำอธิบาย ≤ 1 บรรทัด, กดดูรายละเอียดได้เสมอ
- มือถือ: ไม่มี horizontal scroll, ตารางแปลงเป็นการ์ด

### Validation
- component tests (drawer/modal/badge/filter) ผ่าน
- เทียบหน้าตากับ `index.html` จอที่ใช้ component นั้น
