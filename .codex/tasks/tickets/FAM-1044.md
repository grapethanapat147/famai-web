# FAM-1044 · Dashboard → คลิกรถค้างเปิดคันนั้นใน /stock (deep-link)

**Epic:** FAM-E13 (UI/ธีม track — polish รอบ 4)
**สถานะ:** In Progress (branch feat/dashboard-deeplink)
**ที่มา:** เกรพ — "เพิ่ม deep-link ให้คลิกรถคันนั้นได้เลย" (ต่อ FAM-1043)

## ทำอะไร
- **แถว "รถค้างนานสุด" ใน Dashboard** → เป็นลิงก์ `/stock?unit=<id>` (ต่อแถว) + hover feedback
- **/stock อ่าน `?unit=`** ที่ server (page รับ `searchParams`) → ส่ง `initialUnitId` เข้า StockView
- **StockView** เปิดแผงรายละเอียด (Drawer) ของคันนั้นทันทีตอนโหลด — lazy-init `selected` จาก `initialUnitId` (ไม่ใช้ effect/useSearchParams → กัน lint set-state-in-effect + ไม่ต้อง Suspense)
- unit ที่ deep-link มาจาก dashboard = ผ่าน RLS เดียวกัน → user เห็นได้เสมอ · ไม่เจอ → drawer ปิดเงียบ
- `/dev/stock` รับ `?unit=` ด้วย (harness เทสได้โดยไม่ต้องล็อกอิน)

## Verify
- `/dev/stock?unit=2` → Drawer เปิดคัน NMAX (BTF200) อัตโนมัติ (รหัสรุ่น/สาขา/เลขเครื่อง/อายุ 699 วัน/ต้นทุน) ✓
- `/dev/dash` แถวรถค้าง → href `/stock?unit=u3` (XMAX), `u8` (R15 M), `u2` (NMAX) · footer `/stock` ✓
- tsc + eslint + vitest (235) + build ผ่าน · console สะอาด
- คลิกจริงจาก dashboard → เปิดคันนั้น = เกรพเทสตอน login (dashboard dev ลิงก์ไป /stock จริง)

## หมายเหตุ
- ปิด Drawer แล้ว URL ยังมี ?unit=<id> ค้าง (ไม่ re-open เพราะเป็นค่าเริ่มต้นครั้งเดียว) — ไม่กระทบ ถ้าอยากล้าง URL ตอนปิดค่อยเพิ่ม router.replace ทีหลัง
