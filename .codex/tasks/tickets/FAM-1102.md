## Phase 1 ✅ (branch feature/FAM-1102-acct-receipts) — เมนูบัญชี + ออกใบเสร็จ + พิมพ์
**ไม่ต้อง migration** — ใช้ `document` + `next_doc_no()` + `doc_counter` ที่มีอยู่แล้ว
- เมนู **"บัญชี"** (กลุ่มลูกค้าและการเงิน · admin/manager/acct)
- หน้า list เอกสาร (เลขที่/ประเภท/ลูกค้า/วันที่/ยอดรวม) + ค้นหา
- **ปุ่ม "+ ออกใบเสร็จ"** → เลือกการขาย (combobox พิมพ์ค้น) → `issueReceipt` สร้าง document(RECEIPT)
  - เลขรันอัตโนมัติ `next_doc_no(บริษัท, RECEIPT, ปีพ.ศ.)` · กันออกซ้ำ
  - **snapshot** ผู้ขาย(บริษัท)/ผู้ซื้อ(ลูกค้า) ณ วันออก + แยกยอด base/vat/total
- **พิมพ์** `PrintableReceipt` (หัวบริษัท/ที่อยู่/เลขภาษี · ลูกค้า · รายการรถ+เลขถัง/เครื่อง · VAT · รวม · ช่องเซ็น) ตาม format ตัวอย่าง
- pure: canManageAccount/docTypeLabel/amountBreakdown + test · database.types +document

## Phase 2 ✅ (branch feature/FAM-1102-p2-taxinv) — ใบกำกับภาษี + แก้ไขทุกช่อง (ยกเว้นเลข) + ยกเลิก
- ออกใบกำกับภาษี (TAXINV) แยก — ต้องมีใบเสร็จก่อน · คัด snapshot/ยอดจากใบเสร็จ · เลขรัน TAXINV แยกชุด · กันซ้ำ
- แก้ไขเอกสาร: วันที่/ผู้ขาย/ผู้ซื้อ/รายการรถ/มูลค่า+VAT — **ยกเว้นเลขที่/ประเภท** (ฟอร์มไม่ส่ง → เปลี่ยนไม่ได้) · เลข auto เรียงเสมอ
- ปุ่มคิด VAT 7% · รวม = มูลค่า+VAT สด · เอกสารยกเลิกแล้วแก้ไม่ได้ · ยกเลิก (voided_at, คงเลข) · ออกใหม่ได้
- พิมพ์เพิ่มบรรทัด "ตัวอักษร" (bahtText) · ไม่ต้อง migration (RLS for all + buyer_snapshot.item)
