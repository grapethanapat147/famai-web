### Summary
พอร์ต design system เป็นฐานจริง: CSS variables/tokens (§11.1 สี, 8 token), ฟอนต์ไทย **โฮสต์เอง** (Noto Sans Thai — ตามที่ v1.1 ใช้; ไม่โหลด Google Fonts), และ app shell มือถือเป็นจอหลัก — แถบเมนูล่าง + ปุ่มขายลอย (v1.2) + topbar; เดสก์ท็อปเป็น sidebar

### Acceptance Criteria
- tokens ครบตาม §04/§11.1 ใช้ผ่าน Tailwind theme + CSS vars, รองรับสลับฟอนต์มีหัว/ไม่มีหัว (ค่าเริ่มต้น = ไม่มีหัว)
- ฟอนต์ไฟล์อยู่ในโปรเจกต์ (woff2), ไม่มี request ออก Google Fonts
- shell: มือถือ bottom-nav + ปุ่มขายลอย, เดสก์ท็อป sidebar `--ink`; ไม่มี horizontal scroll บนมือถือ (§v1.4)
- เมนูยึดโครง 20-24 หน้าจอจาก `index.html` (`MENU`) — โครงเปล่าก่อน (หน้า route มาทีหลัง)
