## ปัญหา

## ทำอะไรบ้าง
**ข้อ 16** — `ServiceJob` เพิ่ม `frameNo` (ดึงจากใบงาน ไม่มีก็ตกไปเอาจากคันรถ)
`filterJobs` ค้นเลขถังด้วย · placeholder เปลี่ยนเป็น "ค้นเลขงาน / ลูกค้า / รถ / เลขเครื่อง / เลขถัง"
(เดิมไม่บอกว่าค้นอะไรได้บ้าง คนหน้าร้านจึงไม่รู้ว่าลองได้)

**ข้อ 17** — แยกบล็อกประวัติลูกค้าออกจาก `DealView` เป็น `CustomerHistoryPanel` แล้วใช้ร่วมกันสองหน้า
(ไม่ก๊อปโค้ด — แก้ที่เดียวมีผลทั้งคู่)
- หน้าซ่อม: ลิ้นชักใบงานโชว์ "การซื้อ N คัน / การบริการ N ครั้ง"
- ประวัติการซื้อโหลดจาก `sale` + `registration` เฉพาะลูกค้าที่มีใบงานอยู่ในหน้า (ไม่ดึงทั้งตาราง)
- ประวัติบริการใช้ใบงานอื่นของลูกค้าคนเดียวกันที่โหลดมาอยู่แล้ว — ไม่ต้อง query เพิ่ม
- หน้าดีลนับคันที่กำลังเปิดอยู่ด้วย (`includeCurrentPurchase`) หน้าซ่อมไม่นับ
