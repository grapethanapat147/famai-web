# FAM-1080 · ย้าย Vercel function region → Singapore (sin1) แก้เว็บช้า

**Epic:** (perf/ops) · **สถานะ:** In Progress (branch perf/sin1-region)
**ที่มา:** เกรพ — "website โหลดช้า"

## วินิจฉัย (วัดจริง)
- `x-vercel-id: sin1::iad1` → edge เข้าที่สิงคโปร์ แต่ **function รันที่ iad1 (US East)** (default ของ Vercel Hobby)
- ping Supabase famai-motor (xpbdvhfvmpokdnfhoujx) ~60ms จาก SEA → **Supabase อยู่สิงคโปร์**
- สรุป: ผู้ใช้ไทย + DB อยู่สิงคโปร์ทั้งคู่ แต่ function วิ่งไปรันที่ US → ทุก request + ทุก query ข้ามทวีป (baseline ~570ms แม้หน้าที่ไม่แตะ DB)

## แก้
- `vercel.json` เพิ่ม `"regions": ["sin1"]` → function รันที่สิงคโปร์ → ใกล้ทั้ง user และ Supabase

## Verify (หลัง deploy)
- `x-vercel-id` ควรเป็น `sin1::sin1::...` (function ย้ายมา sin1 แล้ว)
- เวลาโหลดลดลงชัด (โดยเฉพาะหน้าที่ query DB เยอะ เช่น /dash)
- ถ้า Hobby ไม่รับ `regions` ใน vercel.json → ตั้งมือที่ Project Settings → Functions → Function Region → Singapore
