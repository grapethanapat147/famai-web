# FAM-1103 · เลิกใช้ "สาขา" → ใช้ "บริษัท" ทั้งระบบ

**Epic:** (rename) · **สถานะ:** Done (branch feature/FAM-1103-branch-to-company)
**ที่มา:** เกรพ — "ต่อจากนี้จะไม่ใช้คำว่าสาขา ให้ใช้บริษัทไปเลย" (แต่ละที่ตั้งมีเลขภาษี/ที่อยู่ของตัวเอง = คนละบริษัท ตามใบเสร็จจริง)

## ทำ
- แทนคำ **"สาขา" → "บริษัท"** ทุกไฟล์ UI (label/placeholder/error/เมนู/หัวเอกสาร/คอมเมนต์) — 50 ไฟล์
  - `branch` (entity/ตาราง/ตัวแปรอังกฤษ) คงเดิม — เปลี่ยนแค่คำไทยที่ผู้ใช้เห็น
  - เมนู "โอนย้ายสาขา"→"โอนย้ายบริษัท" · filter "ทุกสาขา"→"ทุกบริษัท" · หัวเอกสาร "สาขา:"→"บริษัท:"
- แก้ artifact คำซ้ำ (บริษัท/บริษัท) 2 จุด + เทส recv ("เลือกสาขา"→"เลือกบริษัท")

## ยังไม่ทำ (ยกไป FAM-1102 บัญชี)
- ซ่อนบริษัทแม่ FAMAI + ให้ 3 ที่ตั้ง = 3 บริษัท เต็มตัว (หัวใบเสร็จใช้ข้อมูลบริษัทของแต่ละที่)
- ตอนนี้หน้าตั้งค่ายังมี "บริษัท (นิติบุคคล) · FAMAI" (แม่) อยู่ เพราะ action บันทึกยังใช้ — จะจัดตอนทำบัญชี
