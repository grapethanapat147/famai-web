## ปัญหา
`vercel.json` ตั้ง `X-Robots-Tag: noindex` ให้ **ทุกหน้า** — header นี้ชนะ `robots.txt` ที่อุตส่าห์เปิด `/catalog` ไว้
แปลว่าต่อให้เปิดตัวแคตตาล็อกแล้ว Google ก็ไม่เก็บ และไม่มีใครรู้เพราะไม่ขึ้น error
รายการบอกว่า "อย่าลืมเอาออกตอนเปิดตัว" — แต่สิ่งที่ต้องจำเอาออกคือสิ่งที่จะลืม

## ทำอะไรบ้าง
- ย้าย header ไป `next.config.ts` ซึ่งอ่าน env ตอน build ได้ → **สวิตช์ `CATALOG_PUBLIC=true`**
  - ไม่ตั้ง = ทุกหน้า noindex เหมือนเดิม (ปลอดภัยเป็นค่าเริ่มต้น)
  - ตั้ง true = `/catalog`, `/catalog/:code`, `sitemap.xml`, `robots.txt` พ้น noindex · หลังบ้าน/หน้า login/`/status` ยังปิด
- `Referrer-Policy: no-referrer` ยังติดทุกหน้าทั้งสองโหมด
- ตรรกะเป็นฟังก์ชันบริสุทธิ์ `lib/site/robots-headers.ts` + เทส 3 ชุด (จำลองการจับคู่ path ของ Next)
