# FAM-1087 · หน้า deal: เพิ่มลูกค้า (ลีด) + ปุ่มย้อนขั้น

**Epic:** (feature) · **สถานะ:** In Progress (branch feature/FAM-1087-deal-lead-and-revert)
**ที่มา:** เกรพ — 2 อย่างบนหน้า "ลูกค้าและดีล"
1. ปุ่ม "เพิ่มลูกค้า" เก็บข้อมูลลูกค้าไว้ก่อน เพื่อ sales ติดตามการขายในอนาคต
2. ปุ่มย้อนกลับใน drawer เผื่อ sales เผลอกด "ไปต่อ" จะได้ย้อนขั้นได้

## 1) เพิ่มลูกค้า (ลีด)
- ปุ่ม "+ เพิ่มลูกค้า" บนหัวหน้า deal → modal: ชื่อ* · เบอร์ · รุ่นที่สนใจ · ช่องทาง(source) · หมายเหตุ
- `addCustomer`: insert `customer` (owner_id = sales, branch, interested_variant_id, source, stage default 'เข้ามาดูรถ')
  + สร้าง `follow_up_task` (kind ติดตามลูกค้าใหม่, due +3วัน, assigned_to = sales, note) → เข้าระบบติดตาม
- แท็บ "ลีด (n)" บนตัวกรอง → ลิสต์ลูกค้าที่ยังไม่มีการขาย (name/เบอร์/รุ่นที่สนใจ/ช่องทาง/วันที่เพิ่ม)
  + ปุ่ม "เปิดการขาย" ลิงก์ `/sell?name=&phone=&variant=` (prefill ที่มีอยู่แล้ว)
- สิทธิ์: canManageDeal (รวม sales)

## 2) ปุ่มย้อนขั้น
- `regPrev(stage, payMethod)` (คู่กับ regNext) · `revertRegistration`: ย้อน 1 ขั้นใน track
  + เคลียร์ timestamp ของขั้นที่ออก (delivered_at/plate_received_at/approved_at/submitted_at) · CAS กันแข่ง
- drawer: ปุ่ม "← ย้อนกลับ ({prev})" ข้างปุ่มไปต่อ (โชว์เมื่อมี prev + canManage + ไม่ตกราง)
