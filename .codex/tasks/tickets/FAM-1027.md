# FAM-1027 · เปิดใบงานซ่อมใหม่ + แก้รายการ (create/edit service job)

**Epic:** FAM-E04 (บริการและอะไหล่)
**สถานะ:** Done — create-job (FAM-1027) + line editing FAM-1027b (แก้รายการค่าแรง/อะไหล่ + ตัดสต๊อก) ครบแล้ว
**ขึ้นกับ:** FAM-1012 (หน้าศูนย์ซ่อมตอนนี้ list + เลื่อนสถานะ ยังเปิดงานใหม่/แก้รายการไม่ได้)

## เป้าหมาย
เปิดใบงานซ่อมใหม่ (เลือกลูกค้า/รถในร้านหรือรถนอก, อาการ, ประเภท, เลขไมล์, ช่าง)
และเพิ่ม/แก้รายการ (ค่าแรง + อะไหล่) → คำนวณ labor_cost/parts_cost/total

## ขอบเขต
- ฟอร์มเปิดงาน: job_no ผ่าน `next_doc_no(..., 'SERVICE', ปี พ.ศ.)` · ลูกค้า (มี/ใหม่) · รถในร้าน (unit_id) หรือ รถนอก (engine_no/frame_no)
- เพิ่ม line: labor (description + amount) หรือ part (เลือกจาก `part` → **ตัดสต๊อกอัตโนมัติ** ผ่าน part_movement kind=job, compare-and-swap)
- คำนวณ labor_cost = ผลรวม labor · parts_cost = ผลรวม part · total = ผลรวมทั้งหมด (ฝั่ง server)
- มอบหมายช่าง (technician_id)
- ทั้งหมดตรวจสิทธิ์ service ซ้ำใน action + RLS branch

## หมายเหตุ
- การเพิ่ม part line + ตัดสต๊อก + อัปเดตยอด = หลายตาราง → พิจารณา RPC `add_service_line()` ให้ atomic
  (มิเรอร์ sell_unit/add_model) หรือ compare-and-swap แบบ FAM-1010
- เตือนเช็กระยะ (`service_reminder`) แยกงานปฏิทิน/แจ้งเตือน
