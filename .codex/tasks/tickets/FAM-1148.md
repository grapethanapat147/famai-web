# FAM-1148 — sync กระดาน + บันทึกการตัดสินใจเลื่อน FAM-1141

**สถานะ:** Done
**สาขา (git):** `chore/FAM-1148-board-sync-and-defer`
**ต้องรัน SQL:** ไม่ต้อง

## ทำอะไรบ้าง
**กระดาน** — ประกอบ `done.md` กลับจาก `git log main` ใหม่: 136 → **143 ใบ**
(เพิ่ม FAM-1140 · 1142–1147) พร้อมอัปเดตวันที่ sync ของกระดานอื่น

**แก้กฎการประกอบกระดาน** — เดิมใช้แค่ "id โผล่ใน commit ของ main = เสร็จ"
ซึ่ง**ผิดกับ FAM-1141**: ไฟล์ตั๋วอยู่ใน main แล้ว (ถูก commit ตอน FAM-1140) และ id ถูกอ้างถึง
ในข้อความ commit ของตั๋วอื่นอีกหลายใบ — แต่ตัวงานยังไม่ได้ทำ
กฎใหม่จึงข้ามตั๋วที่ไฟล์ระบุ `สถานะ: Backlog` และเขียนกำกับไว้ในหัว `done.md` แล้ว

**บันทึกการตัดสินใจของเจ้าของ** — เกรพเลือกเลื่อนกลุ่มที่เหลือของ FAM-1141
ไปทำหลังเปิดใช้จริง (5 ก.ย. 2569) เขียนลงทั้งตัวตั๋วและ `backlog.md`
พร้อม **เหตุผล** และ **กับดักที่ต้องรู้ก่อนทำ** (สรุปจาก FAM-1147) เพื่อไม่ให้ใครมาหยิบทำต่อ
โดยเข้าใจว่าเป็นงาน revoke ธรรมดา แล้วทำเส้นทางหลักของร้านพัง
