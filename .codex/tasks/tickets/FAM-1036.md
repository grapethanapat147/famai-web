## เป้าหมาย
อ่านไฟล์รับรถจากระบบยามาฮ่า → แม็ปคอลัมน์ → พรีวิว+ตรวจ → นำเข้า motorcycle_unit เป็นชุด

## ที่มา
- ไฟล์ยามาฮ่า export (reference/yamaha-export/*.xls, parsed-50-units.csv) คอลัมน์ไทย: แบบรถ(รหัสรุ่น)/รหัสสี/เลขเครื่อง/เลขตัวถัง/ต้นทุน+ภาษี/วันที่ใบรับ/DOC_BRANCH_CODE
- **ห้ามเพิ่ม dependency** → parse CSV/TSV ด้วย pure JS (แปลง .xls→.csv ด้วย Excel ก่อน) · roles: admin/manager/stock

## ขอบเขต (in)
- Route `/imp` (SSR ผ่าน RLS): หน้ากันด้วย canManageImport · โหลด model_variant(code→ชื่อ) + branch codes ไว้ resolve/preview
- **parseCsv** (pure): BOM, ฟิลด์ในเครื่องหมายคำพูด, escape, เดาตัวคั่น (คอมมา/แท็บจาก Excel), ตัดบรรทัดว่าง
- **extractUnits**: แม็ปหัวคอลัมน์ไทย → ฟิลด์ · **basicErrors/duplicateEngines**: ตรวจครบ/ซ้ำในไฟล์
- UI: เลือกไฟล์ .csv หรือวางข้อความ → "ตรวจไฟล์" → **พรีวิวตาราง** (รุ่น/สี/เลขเครื่อง/ต้นทุน/รับเข้า/สถานะ) + สรุป พร้อม/มีปัญหา
- ปัญหาที่จับ: ไม่มีรหัสรุ่น/เลขเครื่อง/ตัวถัง · ต้นทุนผิด · **รหัสรุ่นไม่รู้จัก** · เลขเครื่องซ้ำในไฟล์ · เตือนสาขาไม่รู้จัก
- **importUnits** action: ด่านสิทธิ์ + resolve รหัส→id (variant/branch, fallback สาขาผู้ใช้) + **ข้ามเลขเครื่องซ้ำในระบบ** + insert ชุดเดียว (status=available, imported_at) → คืน นำเข้า/ข้าม
- helper บริสุทธิ์ + tests (7 เคส): parseCsv (BOM/quote/tab) · extractUnits (แถวยามาฮ่าจริง) · basicErrors/duplicateEngines
- `/dev/imp` preview (มีตัวอย่าง 3 คัน: 2 ดี 1 ปัญหา) + verify desktop/mobile ไม่มี h-scroll
