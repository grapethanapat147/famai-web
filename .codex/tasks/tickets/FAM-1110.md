## ทำ ✅ (branch feature/FAM-1110-existing-customer)
### RPC `sell_unit` (+ `p_customer_id uuid default null`)
- ส่ง id มา = ใช้ลูกค้าเดิม · ไม่ส่ง = สร้าง walk-in ใหม่ (พฤติกรรมเดิม ไม่ระเบิดของเก่า)
- **ตรวจสิทธิ์ลูกค้าเอง** — security definer ข้าม RLS จึงเช็คว่า customer อยู่ในบริษัทที่ผู้ใช้เข้าถึงได้ (ไม่งั้นดึงลูกค้าข้ามบริษัทได้)
- ชื่อลูกค้าบังคับเฉพาะตอนสร้างใหม่ · เลือกเดิมแล้วเติมเบอร์ให้เฉพาะกรณีระเบียนเดิมยังว่าง (`coalesce` = ไม่ทับข้อมูลเดิม) + อัปเดต stage เป็น "ปิดการขาย"
- re-grant execute หลัง drop (drop ล้าง grant ทิ้ง)

### UI หน้าขายรถ
- ชิปสลับ **"ลูกค้าใหม่ | ลูกค้าเดิม (N)"** (โผล่เมื่อมีลูกค้าในระบบ)
- โหมดลูกค้าเดิม: Combobox **พิมพ์ค้นชื่อหรือเบอร์** → เลือกแล้วเติมชื่อ/เบอร์อัตโนมัติ (ใช้ทำลิงก์ "ไปดีลของ…" ต่อ)
- ปุ่มบันทึกเปิดใช้เมื่อ: โหมดใหม่=กรอกชื่อ · โหมดเดิม=เลือกลูกค้าแล้ว
- บันทึกเสร็จรีเซ็ตกลับโหมด "ลูกค้าใหม่" (กันเผลอผูกคันถัดไปให้คนเดิม)
