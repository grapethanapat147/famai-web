# FAM-1081 · ค้นหาทั่วเว็บ (global search / Cmd+K)

**Epic:** (feature) · **สถานะ:** In Progress (branch feat/global-search)
**ที่มา:** เกรพ — อยากมีปุ่ม search บนแถบบน ค้นรายการทั่วเว็บ

## ทำอะไร
- **`app/api/search/route.ts`** — ค้นรถ (เลขเครื่อง/เลขถัง/รุ่น) + ลูกค้า (ชื่อ/เบอร์) ผ่าน session (RLS คัดสาขา) · ไม่คืนข้อมูลเงิน
- **`components/search/SearchLauncher.tsx`** — ปุ่มค้นหาบนแถบบน + **Cmd/Ctrl+K** → แผงค้นหา · หน้า/เมนู (client) + รถ/ลูกค้า (API, debounce) · ลูกศรเลือก/Enter ไป/Esc ปิด
- **TopBar/AppShell** — ใส่ปุ่ม + ส่งรายการหน้าตามสิทธิ์ (visibleMenu)
- **DealView + deal/page** — รับ `?q=` → prefill ค้นหา (ผลลูกค้าคลิกแล้วไปหน้าดีลกรองชื่อให้)
- รถคลิก → `/stock?unit=<id>` (deep-link เดิม เปิดแผงคันนั้น)
