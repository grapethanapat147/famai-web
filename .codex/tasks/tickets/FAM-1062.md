# FAM-1062 · E08 — ประวัติลูกค้าในแผงดีล (customer history)

**Epic:** FAM-E08 (Customer & Deal) · **สถานะ:** Done (branch feat/customer-history)
**ที่มา:** เกรพ — "ทำประวัติลูกค้าต่อเลย" (ต่อ FAM-1061)

## เป้าหมาย
ทำ "ลูกค้า" เป็น first-class ในหน้าดีล: เปิดดีล → เห็นว่าลูกค้าคนนี้ **เคยซื้อกี่คัน + คันอะไรมาก่อน** (repeat-customer insight) โดย **ไม่ query เพิ่ม** (ใช้ deals ที่โหลดอยู่แล้ว)

## ทำอะไร
- **`Deal` type** — เพิ่ม `customerId` ("" = ลูกค้าทั่วไป ไม่ผูกโปรไฟล์) · deal page เติมจาก `sale.customer_id`
- **`customerDeals(deals, customerId, excludeSaleId)`** (pure) — ดีลอื่นของลูกค้าเดียวกัน เรียงใหม่สุดก่อน · [] ถ้าไม่มี id/ประวัติ + tests
- **DealDrawer** — เพิ่มบล็อก "ประวัติลูกค้า": มีประวัติ → "เคยซื้อรวม N คัน" + list (รถ · วันที่ · ขั้น) · ไม่มี → "ลูกค้าใหม่ — ยังไม่มีประวัติซื้อก่อนหน้านี้"
- dev sample: เติม customerId + เพิ่มดีลเก่าของสมชาย (Grand Filano) เพื่อโชว์ประวัติ
