# FAM-1091 · /models ปุ่ม Edit แก้ไขข้อมูลรุ่น

**Epic:** (quick-win) · **สถานะ:** Done (branch feature/FAM-1091-models-edit)
**ที่มา:** เกรพ (รูป3) — อยากมีปุ่ม Edit ต่อรุ่น เพื่อย้อนกลับมาแก้ข้อมูลได้

## ทำ
- ปุ่ม "✏ แก้ไข" บนการ์ดรุ่นแต่ละใบ (เฉพาะ admin — ตรง RLS model_variant/price_history = is_admin())
- modal แก้ไข: ชื่อรุ่น/ชื่อไทย/ประเภท/cc/ปี + ต้นทุน/ราคาขาย (prefill ค่าปัจจุบัน)
  - รหัสรุ่น **แก้ไม่ได้** (คีย์/กระทบยูนิต) · สี/รูป แก้จากที่เดิม
- `editModel`: update model_variant + **upsert price_history วันนี้** (ราคาใหม่มีผลวันนี้ เก็บประวัติเดิม)
- แยก `validateModelEdit` เป็น pure + test
