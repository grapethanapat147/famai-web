## ปัญหา
`customer.stage` ถูกตั้งตอนสร้างลูกค้า (`เข้ามาดูรถ`) แล้วกระโดดไป `ปิดการขาย` ตอนบันทึกขายเท่านั้น
**ไม่มีโค้ดตรงไหนเปลี่ยนขั้นระหว่างทาง** และตาราง `lead_stage_history` ไม่เคยถูกเขียนเลยสักแถว
ทีมขายจึงไม่รู้ว่าลูกค้าแต่ละคนคุยถึงไหน และควรตามใครก่อน

## ทางเดินขั้น
`เข้ามาดูรถ → สนใจ → ทำสัญญา → ปิดการขาย` · `ไม่ซื้อ` เป็นทางออกที่กดได้จากทุกขั้น

**กฎที่บังคับไว้ทั้ง client และ server:**
- **กด `ปิดการขาย` เองไม่ได้** — ตั้งอัตโนมัติโดย `sell_unit` เท่านั้น ไม่งั้นสถานะจะโกหกว่ามีบิลแล้ว
- ปิดการขายแล้วเปลี่ยนขั้นต่อไม่ได้ · `ไม่ซื้อ` กลับเข้าทางเดินได้ (ลูกค้าเปลี่ยนใจ)
- ถอยขั้นได้ (คุยแล้วถอยกลับไปคิดใหม่เป็นเรื่องปกติ)

## ทำอะไรบ้าง
- `lib/deal/lead-stage.ts` — ลำดับขั้น, `nextLeadStages`, `validateLeadStageChange`, `canChangeLeadStage` (admin/manager/sales)
- action `updateLeadStage` — เปลี่ยน `customer.stage` แบบมีเงื่อนไข (`.eq("stage", ค่าเดิม)` กันสองคนกดพร้อมกันแล้วทับกัน)
  แล้วเขียน `lead_stage_history` (from/to/ใคร/เมื่อไหร่) แบบ best-effort
- ลิสต์ลีดในหน้าดีลโชว์ป้ายขั้น + ดรอปดาวน์ "ย้ายขั้น →" ในแถวเดียวกัน
- เพิ่ม `stage` เข้า `LeadRow` + type `lead_stage_history` ใน database.types
