# FAM-1052 · E11 SEO — sitemap + robots + Open Graph

**Epic:** FAM-E11 (Public Catalog & Status)
**สถานะ:** In Progress (branch feat/catalog-seo)
**ที่มา:** เกรพ — "ดัน E11 ต่อ sitemap/og"

## ทำอะไร
- **`lib/site.ts`** — `siteBaseUrl(env?)` : URL ฐานจาก env (`NEXT_PUBLIC_SITE_URL` → `VERCEL_PROJECT_PRODUCTION_URL`/`VERCEL_URL` → localhost) · pure + tests (+4)
- **`app/sitemap.ts`** — sitemap แบบ dynamic จาก pub.model: `/catalog` (priority 1, daily) + `/catalog/<code>` ทุกรุ่น (0.8, weekly) · revalidate 1h
- **`app/robots.ts`** — `Allow: /catalog` · `Disallow: /` (เปิด index เฉพาะแคตตาล็อก, กันแอดมิน/เครื่องมือส่วนตัว/หน้าล็อกอิน) + ลิงก์ sitemap
- **metadataBase** ใน root layout (จาก siteBaseUrl) → resolve canonical/og relative urls
- **Open Graph + Twitter** บน `/catalog` + `/catalog/[code]`: og:title/description/url/site_name/locale(th_TH)/type + twitter card + `alternates.canonical`
  - **og:image = รูปจริง (full) เมื่อมี** → card เป็น summary_large_image · ยังไม่มีรูป → summary (title+desc) · อัปโหลดรูปแล้ว preview รูปขึ้นเอง
