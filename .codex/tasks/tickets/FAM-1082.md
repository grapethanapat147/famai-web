# FAM-1082 · เร็วขึ้นเวลาสลับหน้า — parallelize getCurrentUser

**Epic:** (perf) · **สถานะ:** Done (branch perf/faster-nav)
**ที่มา:** เกรพ — "อยากให้เร็วขึ้นเวลากดสลับตัวเลือกไปมา"

## วินิจฉัย
- วัดบน production (หลังย้าย region สิงคโปร์): ทุกหน้า ~650-880ms · baseline สูงเท่ากันทุกหน้า = ต้นทุนร่วม ไม่ใช่ query ของหน้านั้น
- `getCurrentUser()` รัน**ทุกหน้า** (ผ่าน layout) แล้วยิง 4 query **ต่อกันทีละอัน**: app_user → app_user_role → role → app_user_branch

## แก้
- `lib/auth/index.ts` — ยิง 4 query **ขนานกัน** (Promise.all): app_user / app_user_role / app_user_branch / role (ตารางเล็ก ดึงทั้งตารางแล้ว filter) → เหลือ round-trip เดียวแทน 4 · ลดเวลาโหลดทุกหน้า
- ปลอดภัย: ผลลัพธ์เท่าเดิม (แค่ยิงพร้อมกัน + filter role ฝั่งโค้ด)
