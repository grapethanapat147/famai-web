# FAM-1134 — ไฟล์แนบใช้งานได้จริง: บิลรับรถ + ใบเสร็จค่าใช้จ่าย (fixlist ข้อ 09)

**สถานะ:** Done
**สาขา (git):** `feature/FAM-1134-attachments`
**ต้องรัน SQL:** ใช่ — `supabase/migrations/20260903120000_37_attachments_bucket.sql`

## ปัญหา
ตาราง `attachment` + RLS มีครบตั้งแต่ migration 04/07 แต่ **ไม่มี bucket ให้เก็บไฟล์ และไม่มีโค้ดอัปโหลดเลย**
บรีฟบอกให้แนบ "บิลรับรถ" กับ "ใบเสร็จค่าใช้จ่าย" ได้ — ตอนนี้ยังทำไม่ได้จริง

## ทำอะไรบ้าง
**migration 37** — bucket `attachments` (ส่วนตัว · 5 MB · JPG/PNG/WebP/PDF) + นโยบาย storage: อ่าน/อัปได้ทุกคนที่ล็อกอิน
ลบได้เฉพาะเจ้าของไฟล์หรือแอดมิน (ตรงกับ RLS ของตาราง) + index ค้นตามแถวเจ้าของ

**แผงไฟล์แนบ (`AttachmentPanel`)** ใช้ร่วมกัน 2 ที่
- **ค่าใช้จ่าย** → รายละเอียดรายการ: แนบ ใบเสร็จ / ใบกำกับภาษี / อื่นๆ (บัญชี, ผู้บริหาร, แอดมิน)
- **สต๊อกรถ** → แผงคันรถ: แนบ บิลรับรถ / ใบทะเบียน / รูปรถ / อื่นๆ (สต๊อก, ผู้บริหาร, แอดมิน)

ขั้นตอน: ตรวจชนิด/ขนาดก่อน (บอกเป็นภาษาคน ไม่ปล่อยให้ storage ปฏิเสธด้วยข้อความอ่านไม่ออก)
→ รูปย่อเป็น WebP ด้าน 1600px ที่เครื่องผู้ใช้ (PDF ส่งตามเดิม) → อัปเข้า bucket จาก client แบบเดียวกับเซลฟี่ลงเวลา
→ server action ผูกกับแถว **โดยตรวจว่า path อยู่ใต้โฟลเดอร์ของแถวนั้นจริง** (กันเอาไฟล์ของรายการอื่นมาผูก)

เปิดไฟล์ = ขอ signed URL อายุ 5 นาทีตอนกด (bucket ส่วนตัว ไม่ฝังลิงก์ยาวในหน้า · หน้าสต๊อกมีเป็นร้อยคัน)
ลบ = ลบ object ก่อนแล้วค่อยลบแถว · เห็นปุ่มลบเฉพาะไฟล์ของตัวเองหรือแอดมิน (ด่านจริงอยู่ที่ action + RLS)

ชื่อไฟล์ทำให้ปลอดภัยก่อนใช้เป็น path: ตัดโฟลเดอร์/`..`/อักขระแปลก แต่**คงตัวอักษรไทยรวมสระ-วรรณยุกต์** (เจอตอนเทส: `\p{L}` ไม่รวมสระไทย)
