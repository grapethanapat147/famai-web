## เป้าหมาย
ปรับ "แบบอักษร" ของทั้งร้านได้ — เลือกคู่ฟอนต์สำเร็จ หรือ **อัปโหลดฟอนต์เอง** (คำขอชัดของเจ้าของ) → เขียน `theme_font_pair` / `theme_custom_font` → engine ฉีดฟอนต์ทั้งแอป

## ทำอะไร (Done)
- **migration 22** `brand-font` bucket (public read สำหรับ @font-face · write เฉพาะ `is_admin()`) · whitelist mime `font/woff2|ttf|otf` · pushed ขึ้น cloud แล้ว
- **`lib/theme/fonts.ts`** (pure) — `FONT_PAIRS` (โนโต+อินเทอร์ = default ตรง globals.css · ไตรรงค์+อนุพันธ์ = blueprint docs/04) + `isValidFontPath` (กัน CSS injection/traversal) + `fontFormat` + `customFontUrl` + tests
- **config/parse** — `ThemeConfig` เพิ่ม `fontPair` + `customFont` · `parseThemeConfig` validate (คู่ไม่รู้จัก→default · path อันตราย→"")
- **`app/layout.tsx`** — โหลด Trirong + Anuphan ผ่าน next/font (var `--f-trirong`/`--f-anuphan`) น้ำหนักน้อยไว้ให้เบา
- **`ThemeStyle`** — ฉีด `--f-display/--f-body` เมื่อไม่ใช่คู่ default · ฟอนต์อัปโหลด → `@font-face` (fm-custom) + override `--f-display` (หัวข้อ) เนื้อความ/ตัวเลขคงเดิม
- **action `updateThemeSettings`** — validate + upsert 3 คีย์ (accent/font_pair/custom_font) พร้อมกัน
- **`ThemeSettings`** — เพิ่มส่วน "แบบอักษร" (radio 2 คู่) + ปุ่มอัปโหลด (.woff2/.ttf/.otf → bucket) + ลบ · พรีวิวสดใช้ฟอนต์ที่เลือก (รวม @font-face พรีวิวฝั่ง client)

## Security
- อัปโหลด: RLS `is_admin()` เท่านั้น (สโมกเทส anon → 403 "new row violates row-level security policy")
- `theme_custom_font` ผ่าน `isValidFontPath` ทั้ง action (เขียน) และ ThemeStyle (อ่าน) ก่อนฝังใน `url('...')` — กัน CSS injection สองชั้น
- bucket public read เฉพาะ (ฟอนต์ไม่ใช่ความลับ) · getPublic 404 NoSuchKey = bucket public+exists

## Verify (browser /dev/settings)
- 2 คู่ฟอนต์ render · กด "ไตรรงค์ + อนุพันธ์" → `--f-display` = Trirong stack + หัวข้อพรีวิว render เป็น Trirong เซอริฟจริง (โหลดสำเร็จ ไม่ใช่ fallback) + aria-pressed
- ปุ่มอัปโหลดแสดง · บันทึก (mock) → "บันทึกธีมแล้ว" · mobile 375 ไม่มี h-scroll · console สะอาด
- tsc + eslint ผ่าน · vitest **227** ผ่าน · build ผ่าน (Trirong/Anuphan fetch สำเร็จ)
- อัปโหลดไฟล์จริง + เปลี่ยนฟอนต์ทั้งแอป = เกรพเทสตอน login (file input ขับ headless ไม่ได้ เหมือน flow รูปรถ)
