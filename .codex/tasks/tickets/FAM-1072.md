# FAM-1072 · Empty states ที่สื่อความหมาย (icon + copy + action)

**Epic:** (polish/hardening) · **สถานะ:** In Progress (branch feat/empty-states)
**ที่มา:** เกรพ — "ทำ empty-state ให้สื่อความหมายขึ้น" · แอปเปิดตัวด้วยข้อมูลว่าง → empty state คือสิ่งแรกที่ผู้ใช้จริงเห็น

## ปัญหาเดิม
ทุกตารางโชว์ข้อความแบน ๆ เหมือนกันหมด + ต่อท้าย "(หรือยังไม่ได้ล็อกอิน)" (ซึ่งใน prod ผู้ใช้ล็อกอินอยู่แล้ว = ทำให้เข้าใจผิด) · ไม่แยก **ยังไม่มีข้อมูลจริง** กับ **กรองแล้วไม่พบ** · ไม่มีทางออก/ปุ่มทำต่อ

## ทำอะไร
- **`components/ui/EmptyState.tsx`** (ใหม่) — ไอคอน (ชุด NavIcon เดียวกับเมนู) + หัวข้อ + คำอธิบาย + ปุ่มทำต่อ (ลิงก์ หรือปุ่ม)
- **`DataTable`** — ขยาย `empty` เป็น `ReactNode` (string เดิม = ห่อการ์ด muted; node = render ตรง เช่น `<EmptyState/>`)
- **10 หน้าตาราง** แยก 2 กรณี — *ว่างจริง* (welcome + CTA/คำแนะนำ) vs *กรองแล้วไม่พบ* (+ปุ่ม "ล้างตัวกรอง" reset): stock (→รับรถ) · deal (→ขาย) · quote (→สร้าง) · parts · service · ar (framing บวก "ไม่มียอดค้างรับ") · transfer · users · attend · expense
- **อีก 4 จุด non-DataTable**: models + ของแถม(parts) → `EmptyState` · payroll + report (อยู่ใน `<td>`) → แก้ข้อความให้สื่อ (ตัด login hint)

- **/dev/stock พิมพ์คำค้นมั่ว → เห็น "ไม่พบรถตามเงื่อนไข" + ปุ่ม "ล้างตัวกรอง"** → กดแล้ว reset กลับมา "กำลังดู: 5 คัน" ✅ (ยืนยันด้วย DOM click; tool-click จอ flaky)
