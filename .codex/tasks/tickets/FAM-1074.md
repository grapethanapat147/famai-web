# FAM-1074 · เอกสารใบขาย/ส่งมอบรถ (PrintableSaleDoc)

**Epic:** FAM-E06 (Sell, Profit & Documents) · **สถานะ:** Done (branch feat/sale-doc)
**ที่มา:** เกรพ — "ทำเอกสารใบขายต่อเลย" (ต่อจาก FAM-1073 ที่พบว่ายังไม่มี component ใบขาย)

## เป้าหมาย
มีเฉพาะใบเสนอราคา (`PrintableQuoteDoc`) ที่พิมพ์ได้ · เพิ่ม **ใบขาย/ส่งมอบรถ** พิมพ์จากแผงดีล — ใช้ระบบ `.print-doc`/`.qdoc-*` ร่วมกัน (FAM-1029)

## ทำอะไร
- **`components/deal/PrintableSaleDoc.tsx`** (ใหม่) — เอกสารเดี่ยว `.print-doc` ใช้ `.qdoc-*`: หัวร้าน/สาขา (ใช้ type `QuoteSeller` เดิม) · เลขที่อ้างอิงจาก saleId (`SL-XXXXXXXX`) · ผู้ซื้อ · ตารางคีย์–ค่า (รุ่น/สี, เลขเครื่อง, ทะเบียน / วิธีชำระ, ไฟแนนซ์+ยอดจัด, **ราคาสุทธิ** เน้น) · ช่องเซ็นผู้ขาย/ผู้ซื้อ · หมายเหตุ (ไม่ใช่ใบกำกับภาษี)
- **`globals.css`** — เพิ่ม `.qdoc-table--kv` (ค่าข้อความชิดซ้าย · แถวราคา strong ชิดขวา) ให้ตารางคีย์–ค่าอ่านสวย
- **DealView/DealDrawer** — รับ prop `seller` · ปุ่ม **"พิมพ์ใบขาย"** ในแผง → `window.print()` · render `<PrintableSaleDoc>` (ซ่อน) ของดีลที่เลือก
- **`app/(app)/deal/page.tsx`** — สร้าง `seller` จาก branch+company ตามสาขาผู้ใช้ (มิเรอร์หน้า quote) แล้วส่งให้ DealView
- **`app/dev/deal/page.tsx`** — ใส่ seller ตัวอย่างไว้พรีวิว

## ข้อมูลที่ใช้ (จาก Deal ที่มีอยู่)
customerName · vehicle (รุ่น·สี) · engineNo · plateNo · payMethod · netPrice · soldAt · finance (บริษัท+ยอดจัด) — ไม่มีฟิลด์ VAT/ที่อยู่ลูกค้า จึงทำเป็น "สรุปการขาย/ส่งมอบ" ไม่ใช่ใบกำกับภาษี

## Verify
- build + tsc + eslint + vitest เขียว
- /dev/deal เปิดดีล → มีปุ่ม "พิมพ์ใบขาย" · เอกสารมีเนื้อหาถูก (เช็ค DOM `.print-doc`)
- print: `:has(.print-doc)` (FAM-1073) แสดงเฉพาะเอกสารตอนสั่งพิมพ์
