# FAM-1009 · หน้าข้อมูลรุ่นรถและสี (models catalog)

**Epic:** FAM-E03 (มอเตอร์ไซค์ / สต๊อก)
**สถานะ:** Done (รอเจ้าของ merge + ทดสอบเขียนจริงตอนล็อกอิน admin)
**สาขา:** `feat/models-screen`

## เป้าหมาย
หน้าจัดการ "แคตตาล็อกรุ่นรถ" — รายการ `model_variant` ทุกรุ่น พร้อมสี ราคา (ต้นทุน/ขายปลีก) จำนวนคงคลัง และรูป
ให้ admin/manager เพิ่มรุ่นใหม่ได้ แล้วรุ่นนั้นโผล่ในหน้ารับรถ/ขายทันที

## ที่มา
- spec §9.5 (ข้อมูลรุ่นรถ) + docs/04 §6 ("รุ่นรถและสี" เป็นของหน้าตั้งค่า → จัดกลุ่มใน "ข้อมูลและตั้งค่า")
- R1 (`.codex/specs/revision-1-client-feedback.md` §C สต๊อก/รุ่นรถ):
  - เพิ่มรุ่น: มีทั้ง **ชื่อรุ่น + รหัสรุ่น**
  - **ใส่รูปรถ** (มี `model_photo` + bucket `model-photo` แล้ว)
  - **เอาปุ่ม "ขายคันนี้" ออก** จากหน้ารุ่นรถ
  - แยก **รุ่นรถกับสี** ออกจากกัน (สีเป็นรายการย่อยของรุ่น)

## ขอบเขต (in)
- Route `/models` (SSR, ผ่าน RLS) — อ่าน `model_variant` + `model_color` + `price_history` (ราคาใหม่สุด) + `motorcycle_unit` (นับคงคลัง) + `model_photo` (thumbnail)
- **ต้นทุนถูกตัดฝั่งเซิร์ฟเวอร์** ด้วย `stripMoneyFields` เมื่อไม่มีสิทธิ์ money / customer mode
- เพิ่มเมนู `models` ในกลุ่ม "ข้อมูลและตั้งค่า" (roles: admin, manager)
- ปุ่ม "เพิ่มรุ่น" (เฉพาะ admin) → Modal ฟอร์ม: รหัสรุ่น, ชื่อรุ่น, ชื่อไทย, ประเภท, cc, ปี พ.ศ., สี (หลายสี), ต้นทุน, ขายปลีก
- Server action `addModel` — insert `model_variant` + `model_color[]` + `price_history` (1 แถว, effective วันนี้); RLS บังคับ admin
- **ไม่มีปุ่ม "ขายคันนี้"** (ตาม R1)
- helper บริสุทธิ์ + tests: `parseColors`, `latestPrice`, `buildModelRows`
- `/dev/models` preview (sample + mock action) + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา)
- **อัปโหลดรูปรถ** เข้าฝั่ง storage (`model-photo` bucket) — แยกเป็น FAM-1024 (ต้อง handle ไฟล์ + resize webp + RLS write); หน้านี้ **แสดง** รูปที่มีอยู่แล้วเท่านั้น
- แก้ราคาของแถม (R1) — เป็นของหน้า "อะไหล่และของแถม" (parts) ไม่ใช่หน้านี้
- แก้ไข/ลบรุ่น (edit/delete) — ตามมาถ้าลูกค้าต้องการ
