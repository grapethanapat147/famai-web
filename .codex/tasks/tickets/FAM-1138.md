**ต้องรัน SQL:** ไม่ต้อง

## ปัญหา
`docs/manual/` มี PDF 8 เล่ม แต่เป็นของ **ต้นแบบ `index.html` v1.15** ที่เลิกใช้ไปแล้ว
หน้าจอในคู่มือไม่ตรงกับแอป Next.js ปัจจุบัน และไม่มีของใหม่ทั้งหมดที่ทำมาตลอด:
ขายส่ง B2B · ชุดเอกสาร 3 ใบ · ใบกำกับภาษี · ปิดงวดเงินเดือน · ใบนำส่ง ปกส. · ไฟล์โอนธนาคาร ·
จุดลงเวลา/สาขา · ไฟล์แนบ · ประวัติการแก้ไข · รหัสเช็กสถานะลูกค้า · เฟสดีล 4 ขั้น

ตัวสร้างเดิมก็รันไม่ได้บนเครื่องนี้แล้ว — `tools/manual/build.js` ผูกกับ playwright ที่ `/opt/node22/…`
และ Chromium ที่ `/opt/pw-browsers/` ซึ่งไม่มีอยู่จริง

## ทำอะไรบ้าง

**เนื้อหาคู่มือย้ายเข้าแอป** — `lib/manual/manual.ts`
เป็น TypeScript จึง typecheck ได้และเทสต์ได้ · โครงของคู่มือ (หน้าที่แต่ละบทบาทเห็น · หน้าที่ไม่เห็นและใครทำแทน ·
สายงานที่เกี่ยวข้อง) **คำนวณจาก `MENU` และ `FLOWS` ของจริง** เพิ่มเมนูใหม่แล้วคู่มือรอบหน้ามีให้เอง
ไฟล์นี้เก็บเฉพาะสิ่งที่โค้ดบอกแทนไม่ได้: งานประจำวันทีละขั้น · ตัวอย่างที่เห็นบนจอ · จุดที่มักพลาด

**คู่มือกลายเป็นหน้าหนึ่งของแอป** — `/dev/manual` (สารบัญ) และ `/dev/manual/<เล่ม>` (เล่มพร้อมพิมพ์)
เปิดอ่านบนจอก็ได้ สั่งพิมพ์เองก็ได้ ไม่ต้องล็อกอิน ไม่แตะฐานข้อมูล

**ตัวสร้าง PDF เขียนใหม่** — เหลือแค่ "เปิด next dev → สั่ง Chrome พิมพ์ 8 หน้า"
ใช้ Chrome ที่มีในเครื่อง ไม่พึ่ง playwright และไม่เพิ่ม dependency ใด ๆ
ถ้ามี dev server เปิดอยู่แล้วจะใช้ตัวนั้น (`--port 3010`) แทนการเปิดใหม่

**ภาพหน้าจอเป็น `<iframe>` ของหน้า `/dev/*` จริง ย่อจาก 390px** ไม่ใช่ภาพถ่าย
→ ตัวหนังสือใน PDF คมทุกระดับซูมและค้นหาได้ · ไฟล์เล็กลง · ไม่มีวันเก่ากว่าแอป
(เคยลองถ่ายภาพด้วย Chrome CLI ก่อน แต่ `--window-size` ไม่มีผลกับ layout ในโหมด headless ใหม่
ภาพที่ได้เป็นการครอปหน้าที่จัดวางไว้ที่ 800px จึงโดนตัดขอบขวา — เลิกใช้วิธีนั้น)

**เทสต์กันคู่มือหลุดจากระบบ** — `tests/manual.test.ts` (17 เคส)
เคสสำคัญคือ **อ่าน `role.perms` จาก migration 08 มาเทียบกับตารางสิทธิ์ในคู่มือ**
แก้สิทธิ์ใน DB แล้วลืมแก้คู่มือ → เทสต์แดงทันที · และบังคับว่าทุกหน้าในเมนูต้องมีคู่มือพูดถึง

**เก็บกวาด** — `tools/manual/content.js` (เนื้อหาเก่า) และ `tools/manual/fonts/*.woff2`
(สำเนาซ้ำของ `app/fonts/`) ลบทิ้ง · ที่มาของฟอนต์ย้ายไป `app/fonts/README.md`

**เอกสารที่อัปเดตตาม** — `README.md` (หัวข้อคู่มือพนักงาน + โครงสร้างรีโป) ·
`docs/README.md` (แถว `manual/` จาก "ของต้นแบบ v1.15" เป็น "ใช้ได้") ·
`docs/04-design-system.md` §10 · `docs/08-state-and-handoff.md` (พอร์ตของตัวสร้าง)
