# FAM-1071 · Graceful error / 404 / loading pages (App Router hardening)

**Epic:** (hardening) · **สถานะ:** In Progress (branch feat/graceful-pages)
**ที่มา:** เกรพ — "polish/hardening เพิ่มต่อเลย" หลัง roadmap จบ

## ปัญหา
แอปไม่มี Next.js special files เลย → typo URL หรือ error ตอน runtime เด้งหน้า default ของ Next (ภาษาอังกฤษ สไตล์ dev) ไม่ใช่หน้าแบรนด์ไทย · `notFound()` ถูกเรียกจริง 2 ที่ (`app/(app)/[screen]` เมนูไม่รู้จัก, `app/catalog/[code]` รหัสไม่มี) แต่ยังโชว์ 404 อังกฤษ

## ทำอะไร (4 ไฟล์ใหม่ · ใช้ token/สไตล์เดิม จาก login/หน้าแรก)
- **`app/not-found.tsx`** — 404 แบรนด์ไทย (การ์ดกลางจอ + brand mark + ปุ่ม "กลับหน้าหลัก" → `/`)
- **`app/error.tsx`** (client) — กัน error ทั้ง subtree · ไม่โชว์รายละเอียด · ปุ่ม "ลองใหม่" (reset) + digest เป็นรหัสอ้างอิง + log ไว้ debug
- **`app/global-error.tsx`** (client) — กัน error ระดับ root layout (render `<html>/<body>` เอง + inline style กันพึ่ง CSS ที่โหลดไม่ทัน)
- **`app/(app)/loading.tsx`** — skeleton ใน AppShell ตอนเปลี่ยนหน้า/ดึงข้อมูล (role=status + sr-only "กำลังโหลด")

## Verify
- build + tsc + eslint ผ่าน
- **404 จริง (ไม่ต้อง login):** `/catalog/<รหัสมั่ว>` → เห็นหน้า 404 ไทย
- **error.tsx จริง:** สร้าง route โยน error ชั่วคราว → เห็นหน้า error ไทย + ปุ่มลองใหม่ → ลบ route ทิ้ง
- a11y: brand mark + ปุ่มมี label ไทยชัด · loading มี role=status/sr-only
