## ทำ ✅ (branch feature/FAM-1101-geofence) — P1: พิกัด (เซลฟี่ = P2)
- **opt-in ต่อบริษัท**: ตั้ง geofence แล้ว → ลงเวลาเข้าต้องส่งพิกัด + อยู่ในรัศมี · ไม่ตั้ง = ทำงานเหมือนเดิม (ไม่ต้อง GPS)

## P2 ✅ (branch feature/FAM-1101-p2-selfie) — ถ่ายเซลฟี่ยืนยัน

- bucket `attendance-selfie` **private** (public=false) + RLS อ่าน/เขียนเฉพาะผู้ล็อกอิน (ข้อมูลส่วนบุคคล)
