## FAM-1006: RBAC menu + server money-strip + customer mode

Status: Done
Priority: High
Epic: FAM-E03
Refs: Spec §8.1-8.3 · docs/08-state-and-handoff.md §6 · security-checklist.md

### Summary
บังคับสิทธิ์ 5 ชนิด (`money`/`allBranch`/`editBack`/`approve`/`admin`) ที่ฝั่งเซิร์ฟเวอร์: กรองเมนูตามสิทธิ์, `stripMoneyFields()` ตัดต้นทุน/กำไร/มูลค่าสต๊อก/ยอดจัด ออกจาก response ทุก endpoint ถ้าไม่มี `money`, และ customer mode (สวิตช์แยกจาก role) ซ่อน money-fields ทุกหน้าทันที · ด่านอยู่ในชั้นข้อมูล ไม่ใช่ที่ปุ่ม/CSS (§9b)

### Acceptance Criteria
- เมนูแสดงตามสิทธิ์จริง (admin เข้า users/settings ได้, เซลล์/สต๊อกไม่เห็นหน้าต้นทุน)
- **money-fields ไม่อยู่ใน API response เลย** เมื่อไม่มีสิทธิ์ `money` — พิสูจน์ด้วยการเรียก endpoint ตรง ไม่ใช่แค่ UI
- customer mode ON → cost/profit/margin/stock-value/ยอดจัด หายทุกหน้า (server-enforced)
- unknown role → ซ่อนไว้ก่อน (fail closed); `allBranch` ปิด → เห็นเฉพาะสาขาตัวเอง (สอดคล้อง RLS)

### Validation
- security test (จาก security-checklist §Security test): เซลล์ยิง API ไม่มี cost/profit, customer mode ซ่อนครบ, ข้ามสาขาไม่ได้
- test เมนูต่อ 9 บทบาท

### Notes
- นี่คือ security gate — ต้องผ่าน security review + test ยิง endpoint จริงก่อน Done

### Implementation Notes (ready for review)
เมนูตามสิทธิ์ทำแล้วใน FAM-1005 (`visibleMenu(user.roleCodes)`). รอบนี้เพิ่มแกน money-strip + customer mode:
- `lib/auth/strip-money.ts` (pure) — `stripMoneyFields(rows, canSee, fields)` **ลบฟิลด์ทิ้งทั้งคีย์** (ไม่ใช่ set null) → ไม่ serialize ไป client เลย (spec §8.3, handoff §9b) + `stripMoneyRow`
- `lib/auth/money.ts` (server-only) — `canSeeMoney()` = `perms.money && !customerMode`; `isCustomerMode()` อ่าน cookie
- `lib/auth/actions.ts` — `toggleCustomerMode()` (set cookie + `revalidatePath('/','layout')`)
- shell: TopBar มีปุ่มสลับ (eye/eye-off, เฉพาะผู้มีสิทธิ์ money) + AppShell แสดง**แบนเนอร์เตือน**เมื่อโหมดลูกค้าเปิด
- `proxy.ts` แทน `middleware.ts` (Next 16 convention, เลิก deprecation)

รูปแบบใช้ในหน้าจอ: `const see = await canSeeMoney(); const rows = stripMoneyFields(raw, see, ['cost','cost_vat'])` แล้วส่ง rows+see ให้ client (money-field ไม่หลุดถ้าไม่มีสิทธิ์)

Validation: `tsc` ✅ · `eslint` ✅ · `vitest` ✅ 29/29 (strip-money: ยืนยัน serialize ไม่มีคำว่า cost/ตัวเลขต้นทุน) · `next build` ✅ (26 หน้า + proxy)
Runtime: `/dash` noauth = 307→/login ยังทำงาน
