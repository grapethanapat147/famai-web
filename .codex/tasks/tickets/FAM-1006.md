## FAM-1006: RBAC menu + server money-strip + customer mode

Status: Backlog
Priority: High
Epic: FAM-E03
Refs: Spec §8.1-8.3 · docs/08-state-and-handoff.md §6 · security-checklist.md

### Summary
บังคับสิทธิ์ 5 ชนิด (`money`/`allBranch`/`editBack`/`approve`/`admin`) ที่ฝั่งเซิร์ฟเวอร์: กรองเมนูตามสิทธิ์, `stripMoneyFields()` ตัดต้นทุน/กำไร/มูลค่าสต๊อก/ยอดจัด ออกจาก response ทุก endpoint ถ้าไม่มี `money`, และ customer mode (สวิตช์แยกจาก role) ซ่อน money-fields ทุกหน้าทันที · ด่านอยู่ในชั้นข้อมูล ไม่ใช่ที่ปุ่ม/CSS (§9b)

### Acceptance Criteria
- เมนูแสดงตามสิทธิ์จริง (admin เข้า users/settings ได้, เซลล์/สต๊อกไม่เห็นหน้าต้นทุน)
- **money-fields ไม่อยู่ใน API response เลย** เมื่อไม่มีสิทธิ์ `money` — พิสูจน์ด้วยการเรียก endpoint ตรง ไม่ใช่แค่ UI
- customer mode ON → cost/profit/margin/stock-value/ยอดจัด หายทุกหน้า (server-enforced)
- unknown role → ซ่อนไว้ก่อน (fail closed); `allBranch` ปิด → เห็นเฉพาะสาขาตัวเอง (สอดคล้อง RLS)

### Validation
- security test (จาก security-checklist §Security test): เซลล์ยิง API ไม่มี cost/profit, customer mode ซ่อนครบ, ข้ามสาขาไม่ได้
- test เมนูต่อ 9 บทบาท

### Notes
- นี่คือ security gate — ต้องผ่าน security review + test ยิง endpoint จริงก่อน Done
