# FAM-1025 · add_model() RPC — เพิ่มรุ่นแบบ atomic

**Epic:** FAM-E11 (ความปลอดภัย / ความถูกต้องข้อมูล)
**สถานะ:** Backlog
**ขึ้นกับ:** FAM-1009 (ตอนนี้ addModel ใช้ 3 insert แยก + cleanup best-effort)

## ปัญหา
`app/(app)/models/actions.ts::addModel` เขียน 3 ตาราง (variant → colors → price) ไม่ atomic
ถ้าล้มกลางคัน จะมี cleanup best-effort แต่ถ้า cleanup ก็ล้ม → รุ่นค้างครึ่งใบ

## เป้าหมาย
ย้ายเป็น RPC `add_model(p_code, p_model_name, p_model_th, p_category, p_cc, p_year, p_colors jsonb, p_cost, p_retail, p_vat)`
- plpgsql transaction เดียว → insert variant + colors + price พร้อมกัน (atomic จริง)
- ตรวจ `is_admin()` ในฟังก์ชัน + `security definer` + `set search_path = public`
- คืน variant id · unique violation (23505) → error ที่ addModel แปลงเป็นข้อความไทยเดิม
- `grant execute ... to authenticated`
- migration ใหม่ (เลขถัดจาก sell_unit/company) — เจ้าของ apply ผ่าน console
- แก้ addModel เรียก RPC แทน 3 insert · เพิ่ม type ใน database.types Functions · wrapper ใน lib/rpc + test
