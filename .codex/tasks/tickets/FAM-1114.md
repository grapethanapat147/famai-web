# FAM-1114 — พิกัดลงเวลา: รวบให้เหลือที่ตั้งค่าที่เดียว

**สถานะ:** Done
**สาขา (git):** `feature/FAM-1114-one-location-source`

## ปัญหา
หลัง FAM-1113 พิกัดลงเวลาตั้งได้ **2 ที่**
- หน้า **ตั้งค่าระบบ → บริษัท** เขียนลง `branch.geo_lat/geo_lng/geo_radius_m` (FAM-1101)
- หน้า **สาขา** เขียนลง `branch_site` (FAM-1113)

`clockIn` ใช้ `branch_site` ก่อนเสมอ แล้วค่อยตกไป `geo_*` — แปลว่าถ้าเกรพแก้พิกัดในหน้าตั้งค่า
แต่บริษัทนั้นมีจุดใน `branch_site` อยู่แล้ว **ค่าที่แก้จะไม่มีผลเลยโดยไม่มีอะไรเตือน** นี่คือกับดักที่ต้องปิด

## แนวทาง
ให้ **หน้าสาขาเป็นที่เดียว** ที่ตั้งพิกัด · หน้าตั้งค่าเหลือแค่ `require_selfie` (นโยบาย ไม่ใช่ตำแหน่ง)

- หน้าตั้งค่า: เอาช่องละติจูด/ลองจิจูด/รัศมี ออก แทนด้วยสรุป "มี N จุด" + ลิงก์ไปหน้าสาขา
- หน้าสาขา: บริษัทที่ยังมี `geo_*` ค้างแต่ไม่มีจุด → ขึ้นแถบ **"ย้ายพิกัดเดิมมาเป็นจุดลงเวลา"** กดปุ่มเดียวจบ
  (สร้างแถวใน `branch_site` แล้วล้าง `geo_*` ทิ้ง — ไม่ต้องรัน SQL เอง)
- `clockIn` คง fallback `geo_*` ไว้ตามเดิม พอย้ายครบ fallback จะตายเองเพราะค่าเป็น null
