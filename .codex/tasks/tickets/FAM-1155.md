# FAM-1155 — เลือกสีแล้วต้องเปลี่ยน "ทั้งเว็บ" ไม่ใช่แค่ปุ่ม

**สถานะ:** Done
**สาขา (git):** `feature/FAM-1155-full-theme-tint`
**ต้องรัน SQL:** ไม่ต้อง

## ปัญหาที่เกรพแจ้ง
เลือกสีของตัวเองแล้วเปลี่ยนแค่บางจุด ไม่ใช่ทั้งเว็บ

## สาเหตุ — มีสองเรื่องซ้อนกัน

**1) ทับแค่ 4 โทเคน** ทั้งธีมของร้านและสีส่วนตัวทับแค่ `--accent*` (ปุ่ม/ไฮไลต์/ตัวเลขเน้น)
พื้นหลัง การ์ด หมึก และเส้นขอบ ยังเป็นสีเทากลางเหมือนเดิม ภาพรวมจึงไม่รู้สึกว่าเปลี่ยนสี

**2) บั๊กที่เจอตอนตรวจ — ในธีมมืด สีส่วนตัวไม่ติดเลยสักนิด**
กฎของร้าน (`ThemeStyle`) เรนเดอร์อยู่ใน `<body>` ส่วนสีส่วนตัวถูกแปะไว้ที่ `<head>`
สอง selector มี specificity **เท่ากัน** (`html:root[data-theme="dark"]`) ตัวที่มาทีหลังใน DOM จึงชนะ
= กฎของร้านชนะทุกครั้ง · ธีมสว่างรอดมาได้เพราะร้านที่ใช้สีเริ่มต้นไม่ปล่อยกฎ light ออกมา
นี่คือเหตุผลที่ "เปลี่ยนไม่ทั่ว" จริง ๆ

## ทำอะไรบ้าง
**`deriveSurfaces()`** — ย้อมพื้นผิวและหมึกตามเฉดสีที่เลือก: `--paper` `--paper-2` `--card`
`--ink` `--ink-soft` `--muted` `--hairline` `--hairline-2`

กติกาที่ยึดไว้: **คงค่าความสว่าง (L) ของพาเลตต์กลางเดิมทุกโทเคน** เปลี่ยนแค่ hue กับ saturation ต่ำ ๆ
คอนทราสต์ตัวหนังสือจึงแทบไม่ขยับ (คอนทราสต์ถูกกำหนดด้วยความสว่างเป็นหลัก)
ถ้าไปขยับ L ด้วย ตัวหนังสือจะอ่านยากทันทีเมื่อผู้ใช้เลือกสีอ่อนหรือเข้มจัด

**แก้ specificity** — CSS ของเครื่องใช้ `html:root:root{…}` (ซ้ำ `:root` สองครั้ง)
ชนะกฎของร้านด้วย specificity ไม่ใช่ด้วยลำดับใน DOM ซึ่งเชื่อถือไม่ได้

**ธีมของร้านย้อมทั้งเว็บด้วย** — ไม่งั้นเลือกสีน้ำเงินที่ตั้งค่าระบบจะได้ผลไม่เหมือนเลือกที่ปุ่ม Aa
ร้านที่ยังใช้สีเริ่มต้น (แดงยามาฮ่า) **หน้าตาไม่ขยับเลย** — ธีมสว่างใช้ค่าใน `globals.css` ตรง ๆ
ส่วนธีมมืดยังทับเฉพาะสีเน้นเหมือนเดิม (แดงต้นฉบับเข้มเกินไปบนพื้นมืด)

**ปรับ `--muted` ให้เข้มขึ้นเล็กน้อย** (L 57% → 54%) — ของเดิม `#8b8f98` คอนทราสต์บนขาว ~3.18
เฉียดเกณฑ์อยู่แล้ว พอย้อมเป็นเขียวจะหล่นเหลือ 2.96 ไม่ผ่าน เทสต์จับได้

## เทสต์
`tests/theme-display.test.ts` +16 เคส — เคสสำคัญคือ **คำนวณอัตราคอนทราสต์ตาม WCAG จากสีที่ derive จริง**
ของทั้ง 6 พรีเซ็ต × 2 ธีม: ตัวหนังสือหลักบนพื้นและบนการ์ดต้องผ่าน 4.5:1 · ตัวหนังสือรองผ่าน 3:1 ·
การ์ดต้องไม่กลืนกับพื้นหลัง · สีคนละเฉดต้องให้พื้นหลังคนละสีจริง (ไม่ใช่คืนค่าเดิม) ·
ความสว่างของพื้นต้องยังใกล้พาเลตต์เดิม (ไม่ทำให้จอมืดหรือขาวโพลน) ·
และ CSS ของเครื่องต้องใช้ `:root:root` ทั้งใน UI และในสคริปต์ก่อน paint

## ตรวจกับของจริงแล้ว
- ธีมสว่างย้อมน้ำเงิน: พื้นหลัง `rgb(247,248,252)` · ธีมมืด: `rgb(13,16,23)` — ทั้งหน้าเปลี่ยนสีจริง
- จำลองกฎของร้านวางทีหลังใน DOM แล้ว **สีของเครื่องยังชนะ** (`--accent` `--paper` `--card` เป็นค่าของเครื่องครบ)
