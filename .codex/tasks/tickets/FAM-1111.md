# FAM-1111 · Flow หลักหน้าดีล — คุยกับลูกค้า → ไฟแนนซ์ → เปิดการขาย → ส่งมอบ

**ประเภท:** (fix/UX) · **ที่มา:** เกรพ — "Flow หลักยังผิด ในหน้าลูกค้าและดีล"

## ปัญหา
หน้าดีลโชว์ไปป์ไลน์เป็น 6 ขั้นของ *งานทะเบียน* (ขายแล้ว → ส่งไฟแนนซ์ → อนุมัติ → รอทะเบียน → ป้ายขาว → ส่งมอบแล้ว)
ซึ่งเป็นมุมของฝ่ายทะเบียน ไม่ใช่มุมที่เจ้าของร้าน/เซลล์ใช้จริง และดู "ขายก่อนไฟแนนซ์" ซึ่งกลับลำดับงานจริง

## ทำ ✅ (branch feature/FAM-1111-deal-flow-taxinv) — ไม่ต้อง migration
- `lib/deal/phase.ts` — เฟสหลัก 4 เฟสตามที่เกรพสั่ง **คิดจากระเบียนจริง** (docs/04 §9g กฎ 1: ไม่เก็บสถานะซ้ำเป็นฟิลด์ที่สาม)
  - คุยกับลูกค้า = ลีด (ยังไม่เปิดบิล) · ไฟแนนซ์ = เปิดบิลแล้วแต่เคสสินเชื่อยังไม่จบ (เงินผ่อน)
  - เปิดการขาย = บิลเดินอยู่ (อนุมัติ/ทะเบียน/ป้าย) · ส่งมอบ = ปิดดีล
- ชิปกรองหน้าดีล = 4 เฟส (มีเลข 1-4 + ตัวนับ) · กด "คุยกับลูกค้า" → สลับไปลิสต์ลีดให้เลย · ชิป "ตกราง" แยกไว้เมื่อมี
- ตารางดีล: คอลัมน์ "ขั้น" → **"เฟส"** (ป้ายเฟส + ขั้นละเอียดตัวเล็กใต้)
- ดรอว์เออร์: StepBar บนสุด = 4 เฟส + บรรทัด "เฟสปัจจุบัน: X · <คำอธิบายว่าต้องทำอะไร>"
  แล้วค่อยเป็น **"ขั้นละเอียด (งานทะเบียน)"** 6 ขั้นเดิม (ยังกดบันทึกสถานะย่อย/หมายเหตุได้เหมือนเดิม)
