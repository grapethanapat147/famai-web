# FAM-1063 · E08 — รวมประวัติบริการในแผงดีล (service history)

**Epic:** FAM-E08 · **สถานะ:** In Progress (branch feat/customer-service-history)
**ที่มา:** เกรพ — "รวมประวัติบริการต่อเลย" (ต่อ FAM-1062)

## เป้าหมาย
ต่อยอดประวัติลูกค้า (FAM-1062 = การซื้อ) ให้เห็น **การบริการ** ของลูกค้าด้วย → เห็นความสัมพันธ์ครบ (ซื้อ + เข้าศูนย์)

## ทำอะไร
- **`ServiceHistory` type + `customerServices(rows, customerId)`** (pure) — งานบริการของลูกค้าเดียวกัน เรียงใหม่สุดก่อน · [] ถ้าไม่มี id + tests
- **deal page** — query `service_job` (customer_id, service_type, checked_in_at, status, total) → ส่ง `services` เข้า DealView (service_job มีใน types แล้ว ไม่ต้องแก้)
- **DealDrawer** — จัดบล็อก "ประวัติลูกค้า" เป็น 2 ส่วน:
  - **การซื้อ · N คัน** (เดิม)
  - **การบริการ · M ครั้ง** — list (ประเภท · วันที่ · ยอด) · ไม่มี → "ยังไม่เคยเข้าศูนย์บริการ"
- dev sample: เติม SERVICES (สมชาย 2 ครั้ง, วิภา 1 ครั้ง)
