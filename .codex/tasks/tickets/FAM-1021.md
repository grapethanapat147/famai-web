# FAM-1021 · หน้ารายงาน (report) — สรุปแยกประเภท + ส่งออก/พิมพ์

**Epic:** FAM-E01 (ภาพรวม)
**สถานะ:** Done (verify ครบ — read-only ล้วน ทดสอบได้เต็ม)
**สาขา:** `feat/report-screen`

## เป้าหมาย
รายงานสรุปแยกประเภท (ขาย/ค่าใช้จ่าย/เงินค้างรับ) จัดกลุ่ม + ช่วงวันที่ + ส่งออก CSV / พิมพ์
(เมนู subtitle: "สรุปแยกประเภท พิมพ์และส่งออกได้")

## ที่มา
- อ่านจากตารางที่ทำมาครบแล้ว: `sale` · `expense` · `receivable` (+ join รุ่น/สาขา/พนักงาน/หมวด)
- roles: admin/manager/acct/stock/hr · **read-only** (ไม่มี write) → verify ได้เต็ม
- money guard: กำไร (gross_profit) ตัดฝั่งเซิร์ฟเวอร์ตาม canSeeMoney

## ขอบเขต (in)
- Route `/report` (SSR ผ่าน RLS): ดึง sale (ยังไม่ยกเลิก) + expense + receivable แล้ว normalize
- ตัวเลือกรายงาน: **ยอดขาย / ค่าใช้จ่าย / เงินค้างรับ**
- ยอดขาย: ช่วงวันที่ + จัดกลุ่ม ตามรุ่น/สาขา/พนักงาน/เดือน · คอลัมน์ จำนวน · ยอดสุทธิ · **กำไร (money-guard)**
- ค่าใช้จ่าย: ช่วงวันที่ + จัดกลุ่ม ตามหมวด/เดือน · คอลัมน์ จำนวน · ยอดรวม
- เงินค้างรับ: (snapshot) จัดกลุ่มตามประเภท · คอลัมน์ จำนวน · ยอดค้าง (เฉพาะที่ยังค้าง)
- ตารางมีแถวรวมท้าย · เรียงมาก→น้อย · **ส่งออก CSV** (BOM + escape RFC4180) · **พิมพ์** (print: utilities)
- helper บริสุทธิ์ + tests (6 เคส): inRange/groupAggregate/sumColumn/totalCount/monthKeyBE/toCsv
- `/dev/report` preview + verify desktop/mobile ไม่มี h-scroll

## ขอบเขต (out / ตามมา)
- รายงานเพิ่ม: สต๊อก/aging, ศูนย์ซ่อม, คอมมิชชั่น · กราฟ (bar/line) · เทียบช่วงก่อน
- กำหนดช่วง preset (เดือนนี้/ไตรมาส) · ส่งออก Excel/PDF · กำหนดคอลัมน์เอง
