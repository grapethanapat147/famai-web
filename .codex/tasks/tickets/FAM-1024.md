# FAM-1024 · อัปโหลดรูปรถเข้า storage (model-photo)

**Epic:** FAM-E03 (มอเตอร์ไซค์ / สต๊อก)
**สถานะ:** Backlog
**ขึ้นกับ:** FAM-1009 (หน้ารุ่นรถและสี — แสดงรูปได้แล้ว ยังอัปโหลดไม่ได้)

## เป้าหมาย
ให้ admin อัปโหลดรูปรถ (card + full) ในหน้ารุ่นรถและสี → เข้า bucket `model-photo` (public, มีอยู่แล้ว migration 13)
แล้วรูปโผล่ในการ์ด /models และ pub.model (เว็บขายรถ)

## ที่มา
R1 (`.codex/specs/revision-1-client-feedback.md` §C): "เพิ่มรุ่น ... **ใส่รูปรถ**"

## ขอบเขต
- ปุ่ม/โซนอัปโหลดใน AddModelModal + การ์ดรุ่น (แก้ไขรูปภายหลัง)
- resize เป็น webp (เจ้าของสั่ง: "quality ดีแต่ประหยัดพื้นที่", limit 2MB, mime webp/jpeg)
- insert `model_photo` (variant_id, path_card, path_full, sort 0–3, alt)
- RLS write: policy `model_photo_write` (ดู migration 13) — ตรวจสิทธิ์ให้ตรง (admin)
- ลบ/จัดลำดับรูป (sort)

## เปิดค้าง
- ทำ resize ฝั่ง client (canvas/webp) หรือ server (sharp) — ตัดสินใจตอนเริ่ม
- ต้องล็อกอินถึงทดสอบ upload ได้
