# FAM-1129 — โอนข้ามบริษัทไม่ได้ ต้องเปิดบิลขายส่ง (บรีฟ R1 B1)

**สถานะ:** Done
**สาขา (git):** `feature/FAM-1129-transfer-company-rule`
**ต้องรัน SQL:** ไม่ต้อง

## สิ่งที่พบก่อนลงมือ
บรีฟ B1 บอกว่า "โอนย้าย: บริษัท→บริษัท ทำไม่ได้ ต้องเปิดการขายระหว่างบริษัท"
**ตรวจแล้วกฎนี้บังคับอยู่แล้วในเซิร์ฟเวอร์** (`sameCompany` ใน `requestTransfer`) และมีเทสครอบด้วย
จึงไม่ต้องเขียนกฎใหม่ — สิ่งที่ขาดคือ **คนใช้จะรู้ก็ต่อเมื่อกดส่งไปแล้วโดนปฏิเสธ**
และตอนนั้นยังไม่มีหน้าขายส่งให้ไปทำต่อ (เพิ่งมีใน FAM-1127)

## ทำอะไรบ้าง
- **ปิดปลายทางข้ามบริษัทตั้งแต่ในฟอร์ม** — ดรอปดาวน์ขึ้น "Famai Chonburi — คนละบริษัท (ต้องขายส่งแทน)"
  และเลือกไม่ได้ · บริษัทต้นทางเองก็ปิดพร้อมป้าย "ต้นทางเอง" (เดิมเลือกได้แล้วค่อยโดนปฏิเสธ)
- **อธิบายพร้อมทางออก** ใต้ฟอร์มมีข้อความบอกว่าการย้ายข้ามนิติบุคคลถือเป็นการขาย พร้อม**ลิงก์ไปหน้าขายส่ง (B2B)** ได้เลย
- ข้อความปฏิเสธฝั่งเซิร์ฟเวอร์เดิมว่า "ต้องเปิดการขายระหว่างบริษัท" (ลอย ๆ ไม่บอกว่าที่ไหน)
  เปลี่ยนเป็นชี้ไปหน้าขายส่งตรง ๆ

ด่านฝั่งเซิร์ฟเวอร์ยังอยู่เหมือนเดิม — UI เป็นแค่ชั้นที่ช่วยไม่ให้เสียเวลา ไม่ได้แทนที่การบังคับจริง
