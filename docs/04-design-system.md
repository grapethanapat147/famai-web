## 1. 🔴 กฎที่สำคัญที่สุด — แดงเป็นช่วงเวลา ไม่ใช่พื้นผิว

แดงคือสีแบรนด์ยามาฮ่า แต่บลูพรินต์ห้ามเอาสีเน้นไปถมเป็นพื้นผิว
ทางออกคือใช้แบบเดียวกับตัวอย่าง `.cta` ของบลูพรินต์เอง — **พิลล์หมึก + รายละเอียดสีเน้น**

| ที่ | ใช้อะไร |
|---|---|
| ปุ่มหลัก | พื้น**หมึก** `#16181D` + **ลูกศรแดง** |
| เมนูที่เลือก | พื้นขาว + **ขีดแดง 2px ด้านซ้าย** + ไอคอนแดง |
| แท็บที่เลือก | **ขีดแดง 2px ใต้ข้อความ** |
| กราฟแท่ง | **หมึก** — แดงเฉพาะแท่งที่เกินเกณฑ์ |
| แถบโปรโมชัน | การ์ดขาว + **จุดแดง** |
| แดงใช้ที่เหลือ | ลิงก์ · focus ring · โลโก้ · ตัวเลขที่ต้องรีบจัดการ |

**ผลพลอยได้:** แดงหลุดจากการเป็นสี "ผิดพลาด" ได้จริง — ปัญหาที่บันทึกไว้ใน `01-gap-analysis.md` §4.7
ตอนนี้สถานะสื่อด้วย **ข้อความ + จุดสี ไม่มีพื้นสี** ซึ่งสงบตากว่าและอ่านง่ายกว่า

## 2. Token ทั้งหมด

```css
:root{
  /* Canvas */
  --paper:#FAFAF8;  --paper-2:#F4F3EF;  --card:#FFFFFF;  --dark:#0E0F12;

  /* Ink — หมึกหนึ่ง หมึกอ่อนหนึ่ง เทาหนึ่ง */
  --ink:#16181D;  --ink-soft:#3A3E47;  --muted:#8B8F98;
  --hairline:rgba(22,24,29,.12);  --hairline-2:rgba(22,24,29,.06);
  --hairline-dark:rgba(255,255,255,.10);

  /* Accent — หนึ่งเดียว สองตัวแปร */
  --accent:#E60012;  --accent-hover:#FF2B39;  --accent-deep:#B3000E;
  --accent-wash:rgba(230,0,18,.06);

  /* สถานะ — ข้อความกับจุด ไม่มีพื้นสี */
  --pos:#1F7A4D;  --attn:#A96410;

  /* Spacing — 8-point */
  --s-half:4px; --s1:8px; --s2:16px; --s3:24px; --s4:32px; --s5:48px; --s6:64px;

  /* Radii */
  --r-input:8px; --r-card:12px; --r-lg:16px; --r-btn:24px; --r-pill:999px;

  /* Shadow — ย้อมสีหมึก ไม่ใช่ดำล้วน */
  --sh-sm:0 1px 2px rgba(22,24,29,.06);
  --sh-md:0 8px 24px rgba(22,24,29,.10);
  --sh-lg:0 20px 50px rgba(22,24,29,.16);
  --glow:0 0 30px rgba(230,0,18,.28);

  /* Type — แปดขนาด */
  --t-label:12px; --t-table:14px; --t-body:15px; --t-lead:18px;
  --t-h2:20px; --t-h1:28px; --t-stat:32px; --t-display:34px;

  /* Font */
  --f-display:'Trirong', Georgia, serif;
  --f-body:'Inter', 'Anuphan', system-ui, sans-serif;

  /* Motion */
  --ease:cubic-bezier(.16,1,.3,1); --dur-ui:.3s; --dur-in:1s;
}
```

> `--s-half` (4px) เป็นครึ่งขั้นที่อนุญาตไว้เฉพาะช่องไฟภายในคอนโทรลเล็ก
> ส่วนจังหวะของเลย์เอาต์ใช้ 8-point เท่านั้น

## 3. ตัวอักษร

| บทบาท | ฟอนต์ | ใช้กับ |
|---|---|---|
| Display | **Trirong** (serif ไทย+ละติน) | ชื่อหน้า · หัวการ์ด · ตัวเลข KPI · หัวเอกสาร · โลโก้ |
| Body | **Inter** + **Anuphan** | เนื้อหา ตาราง ฟอร์ม เมนู |
| สลับได้ | **Sarabun** | ปุ่มสลับฟอนต์มีหัว |

**เหตุผล** — Anuphan ออกแบบมาเพื่อหน้าจอ x-height สูง ช่องเปิดกว้าง อ่านง่ายกว่า IBM Plex Sans Thai
ที่ v0.5–0.6 ใช้ · Inter ให้ตัวเลข tabular ที่จำเป็นกับตารางเงิน · Trirong เพิ่มบุคลิกแบบสิ่งพิมพ์
ซึ่งเป็นสิ่งที่ทำให้หน้าจอ**ไม่ดูเหมือนงานที่ AI ปั๊มออกมา** (ซึ่งมักใช้ sans ตัวเดียวทั้งหน้า)

| Token | ขนาด | line-height | tracking | ตระกูล |
|---|---|---|---|---|
| label | 12 | 1.3 | +0.06em | sans |
| table | 14 | 1.5 | 0 | sans |
| body | 15 | 1.6 | 0 | sans |
| lead | 18 | 1.5 | 0 | sans |
| h2 | 20 | 1.3 | −0.01em | serif |
| h1 | 28 | 1.15 | −0.02em | serif |
| stat | 32 | 1.05 | −0.02em | serif |
| display | 34 | 1.0 | −0.02em | serif |

**กฎ:** ตัวใหญ่ขึ้น → line-height แน่นขึ้น · tracking สวนทางกับขนาด · ตัวเลขทุกที่ใช้ `tabular-nums`

## 4. การแยกพื้นผิว — เลือกอย่างแรกที่ใช้ได้ ห้ามซ้อน

```
1. FILL    ← พื้นที่ต่างสีกัน (ถูกที่สุด สงบที่สุด)
2. SHADOW  ← ถ้า fill ไม่พอ ค่อยยกขึ้น
3. BORDER  ← เฉพาะเมื่อต้องอยู่ระนาบเดียวกันจริง ๆ
```

| องค์ประกอบ | ใช้ |
|---|---|
| การ์ด | พื้นขาวบนกระดาษอุ่น + `--sh-sm` — **ไม่มีเส้นขอบ** |
| ตาราง | hairline อย่างเดียว — **ไม่มีพื้นหัวตาราง** |
| การ์ดใน kanban | พื้น `--paper` อย่างเดียว |
| ฟอร์ม | เส้นขอบ hairline อย่างเดียว |

> v0.6 ซ้อน fill + border + shadow บน `.card` และ `.kpi` พร้อมกัน — บลูพรินต์เรียกสิ่งนี้ว่า
> *"สัญญาณที่ชัดที่สุดของงานสมัครเล่น"* v0.7 แก้แล้ว

## 6. การเคลื่อนไหว

```css
--ease:cubic-bezier(.16,1,.3,1);   /* เส้นโค้งเดียวทั้งระบบ */
--dur-ui:.3s;                      /* ตอบสนอง UI */
--dur-in:1s;                       /* เข้าหน้า */
```

- เข้าหน้า: จาง + เลื่อนขึ้น 24px · ไล่ทีละการ์ด 0.08s
- hover ลิงก์: ลด opacity เป็น 0.6 — **ไม่เปลี่ยนสี**
- กดปุ่ม: `scale(.97)`
- ไม่มี bounce ไม่มี spring
- `prefers-reduced-motion` ปิดทั้งหมด

## 7. กฎการแสดงผลเฉพาะงานนี้

| เรื่อง | กฎ |
|---|---|
| เงิน | `1,354,302 ฿` · คั่นหลักพัน · tabular-nums |
| เงินติดลบ | สีแดง + วงเล็บ |
| วันที่ | พ.ศ. เสมอ `29 ก.ค. 2569` |
| เลขเครื่อง/เลขถัง | monospace |
| อายุสต๊อก | ≤33% ของเกณฑ์ = เขียว · ≤100% = ส้ม · เกิน = แดง |
| ต้นทุน/กำไร | เป็น `—` เมื่อไม่มีสิทธิ์ `money` |
| สถานะ | **ต้องมีข้อความเสมอ** ไม่สื่อด้วยสีอย่างเดียว |
| ปุ่มที่ยังไม่ทำงาน | ห้ามมี |
| คำอธิบาย | ถ้าหน้าจอบอกตัวเองได้ ไม่ต้องเขียน |
