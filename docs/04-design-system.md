## 2. Design tokens

### 2.1 สี

```css
:root{
  /* แบรนด์ */
  --brand:        #E60012;   /* แดงยามาฮ่า — ปุ่มหลัก เมนูที่เลือก กราฟหลัก */
  --brand-pressed:#B3000E;
  --brand-tint:   #FFF1F2;   /* พื้นเมนูที่เลือก / พื้นแท็ก */
  --brand-track:  #FFE0E3;   /* รางพื้นหลังของกราฟแท่ง */
  --on-brand:     #FFFFFF;

  /* กลาง */
  --ink:      #151E23;   /* ตัวอักษรหลัก / ดำ */
  --ink-2:    #6B6C7E;   /* ตัวอักษรรอง */
  --ink-3:    #848A95;   /* label / คำอธิบาย */
  --line:     #EFF0F6;   /* เส้นขอบการ์ด */
  --line-2:   #E4E5E7;   /* เส้นตาราง */
  --bg:       #F5F6F8;   /* พื้นหลังหน้า */
  --card:     #FFFFFF;
  --soft:     #FAFBFC;   /* พื้นหัวตาราง / แถวสลับ */

  /* ความหมาย — ต้องแยกจากสีแบรนด์ให้ชัด */
  --good:     #12B76A;  --good-bg: #ECFDF3;  --good-line: #D1FADF;
  --warn:     #F79009;  --warn-bg: #FFFAEB;  --warn-line: #FEF0C7;
  --bad:      #B42318;  --bad-bg:  #FEF3F2;  --bad-line:  #FEE4E2;
  --info:     #175CD3;  --info-bg: #EFF8FF;  --info-line: #D1E9FF;

  /* รูปทรง */
  --r:      14px;   /* การ์ด */
  --r-sm:   10px;   /* ปุ่ม / input */
  --r-pill: 999px;
  --sh:     0 5px 20px rgba(0,0,0,.05);      /* เงาการ์ด — ตรงตาม Figma */
  --sh-lg:  0 20px 50px -20px rgba(21,30,35,.25);
}
```

### 2.2 🔴 กฎสำคัญ: แดงแบรนด์ ≠ แดงผิดพลาด

ปัญหาที่พบใน v0.5: สีแดงถูกใช้เป็นทั้งสีแบรนด์และสี "ผิดพลาด" ส่วนสี "ดี" กลับเป็นน้ำเงิน
พอเปลี่ยนมาใช้แดงยามาฮ่าเป็นสีหลัก ยิ่งต้องแยกให้ขาด

| ความหมาย | สี | ใช้กับ |
|---|---|---|
| **แบรนด์ / การกระทำหลัก** | `#E60012` สด | ปุ่มหลัก · เมนูที่เลือก · แท่งกราฟ · โลโก้ |
| **ผิดพลาด / ต้องรีบจัดการ** | `#B42318` เข้ม + พื้น `#FEF3F2` | ของหมด · เลยกำหนด · ค่าติดลบ |
| **สำเร็จ** | `#12B76A` | อนุมัติแล้ว · มาตรงเวลา · กำไรบวก |
| **เตือน** | `#F79009` | ใกล้หมด · ใกล้ครบกำหนด · มาสาย |
| **ข้อมูล** | `#175CD3` | หมายเหตุ · สถานะกลาง |

หลักจำง่าย: **แดงสดคือ "กดตรงนี้" · แดงเข้มคือ "มีปัญหา"**
และสถานะห้ามสื่อด้วยสีอย่างเดียว — ต้องมีไอคอนหรือข้อความกำกับเสมอ (เผื่อคนตาบอดสี)

### 2.3 ตัวอักษร

```css
--font-en:     'Inter';
--font-th-nl:  'IBM Plex Sans Thai', 'Noto Sans Thai';          /* ไม่มีหัว */
--font-th-l:   'IBM Plex Sans Thai Looped', 'Sarabun';          /* มีหัว */
--font: var(--font-en), var(--font-th-nl), system-ui, sans-serif;
```

> คงสวิตช์สลับฟอนต์ไทยมีหัว/ไม่มีหัวจาก v0.5 ไว้ — เป็นรายละเอียดที่เข้าใจผู้ใช้ไทยจริง
> ผู้ใหญ่หลายคนอ่านฟอนต์มีหัวได้สบายตากว่ามาก

สเกลตาม Figma:

| ระดับ | ขนาด / น้ำหนัก / ระยะห่าง | ใช้กับ |
|---|---|---|
| Headline | 24 / 700 | ชื่อหน้า |
| Title | 16 / 600 · ls −0.2 | หัวการ์ด |
| Title Medium | 16 / 500 · ls −0.3 | หัวข้อรอง |
| Body 1 | 14 / 500 · ls −0.15 | เนื้อหาหลัก |
| Body 1 Emphasized | 14 / 600 | ค่าที่ต้องเน้น |
| Body 2 | 12 / 400 | คำอธิบาย |
| Body 2 Emphasized | 12 / 600 · ls +0.02 | label เล็ก / หัวตาราง |
| Stat | 28–32 / 700 · tabular-nums | ตัวเลข KPI |

**ตัวเลขทุกที่ต้องใช้ `font-variant-numeric: tabular-nums`** — ไม่งั้นตัวเลขในตารางจะไม่ตรงหลัก

### 2.4 ระยะห่าง

`4 · 8 · 12 · 16 · 20 · 24 · 32 · 40` — ห้ามใช้ค่านอกชุดนี้

| ที่ | ค่า |
|---|---|

## 3. คอมโพเนนต์

### 3.1 KPI card
```
┌──────────────────────┐
│ NET CASH             │  label — 12/600 uppercase สี --ink-3
│ 1,354,302 ฿          │  ตัวเลข 30/700 tabular-nums
│ ▲ 12% เทียบเดือนก่อน  │  delta — 12/500 เขียว/แดงตามทิศทาง
└──────────────────────┘
พื้นขาว · มุม 14px · เงา --sh · padding 20px
```

### 3.2 กราฟแท่ง (ลายเซ็นของดีไซน์)
- แต่ละแท่งมี **รางพื้นหลังสี `--brand-track`** เต็มความสูงเสมอ
- แท่งจริงสี `--brand` ทับบนราง · หัวมน 6px
- แกน Y 4–5 ขีด สี `--ink-3` 11px · ไม่มีเส้นตาราง
- แกน X ตัวหนังสือ 11px

### 3.3 ตาราง
- หัวตาราง: พื้น `--soft` · ตัวอักษร 12/600 · `--ink-2` · ไม่ใช้พื้นดำเหมือน v0.5
- แถว: สูง 44px · เส้นคั่น `--line-2` · hover พื้น `--soft`
- คอลัมน์ตัวเลข: ชิดขวา + tabular-nums
- คอลัมน์สถานะ: ใช้ **pill** ไม่ใช่ข้อความสีเปล่า ๆ
- **มือถือ: ห่อด้วย `overflow-x:auto` เสมอ** — ห้ามให้หน้าเลื่อนแนวนอน

### 3.4 Pill สถานะ
```css
.pill{ display:inline-flex; align-items:center; gap:6px;
  padding:3px 10px; border-radius:var(--r-pill);
  font-size:12px; font-weight:600; border:1px solid; }
```
| สถานะ | สี |
|---|---|
| พร้อมขาย · อนุมัติแล้ว · เสร็จ | `--good` |
| รอดำเนินการ · ใกล้ครบกำหนด | `--warn` |
| เลยกำหนด · ปฏิเสธ · ของหมด | `--bad` |
| จองแล้ว · โอนย้าย | `--info` |
| ขายแล้ว | เทา |

### 3.5 ปุ่ม
| ชนิด | รูปแบบ |
|---|---|
| หลัก | พื้น `--brand` · ตัวขาว · 40px · มุม 10px |
| รอง | พื้นขาว · ขอบ `--line-2` · ตัว `--ink` |
| อันตราย | พื้น `--bad` · ตัวขาว · **ต้องมีกล่องยืนยันเสมอ** |
| ข้อความ | ไม่มีพื้น · ตัว `--brand` |

### 3.6 Sidebar
- ขาว 240px · เส้นขอบขวา `--line`
- โลโก้ FAMAI MOTOR สีแบรนด์ 20/800 + บรรทัดรอง "ระบบหลังบ้าน" 11px เทา
- เมนู 40px · มุม 10px · ไอคอน 18px
- **เมนูที่เลือก:** พื้น `--brand-tint` · ตัวอักษรและไอคอนสี `--brand` · น้ำหนัก 600
- หัวข้อกลุ่ม: 11/600 uppercase `--ink-3` · ระยะห่างบน 20px
- ท้าย: เส้นคั่น + การ์ดโปรไฟล์ (avatar + ชื่อ + บทบาท·สาขา) + ปุ่มออกจากระบบ
- **มือถือ (<900px): ยุบเป็น drawer** เปิดด้วยปุ่มแฮมเบอร์เกอร์ + ฉากหลังทึบ

## 5. การพิมพ์เอกสาร

v0.5 พิมพ์ไม่ได้เลย — v0.6 ต้องพิมพ์ได้จริงด้วย `window.print()` + stylesheet แยก

```css
@media print{
  .side, .top, .noprint { display:none !important; }
  .doc { box-shadow:none; border:0; margin:0; padding:0; }
  @page { size: A4; margin: 12mm; }
  body { background:#fff; font-size:12pt; }
  table { page-break-inside:auto; }
  tr    { page-break-inside:avoid; }
  thead { display:table-header-group; }   /* หัวตารางซ้ำทุกหน้า */
}
```

เอกสารที่ต้องพิมพ์ได้: ใบเสร็จรับเงิน · ใบกำกับภาษี (แบบเต็มรูป) · ใบกำกับภาษีเงินดาวน์ ·
ใบเสนอราคา · ใบงานซ่อม · สลิปเงินเดือน · รายงานสต๊อก

**ทุกใบต้องดึงข้อมูลบริษัทจากหน้าตั้งค่า ไม่ฝังในโค้ด** และใช้เลขที่จากตัวนับที่ไม่ซ้ำ

## 6. การเข้าถึง (Accessibility)

| เรื่อง | เกณฑ์ |
|---|---|
| ความต่างของสี | ตัวอักษรปกติ ≥ 4.5:1 · ตัวใหญ่ ≥ 3:1 |
| แดงบนขาว | `#E60012` บนขาว ≈ 5.0:1 ✅ ใช้กับตัวอักษรได้ |
| ขาวบนแดง | ≈ 4.2:1 — **ใช้กับตัวหนา ≥14px เท่านั้น** ไม่ใช้กับตัวเล็กบาง |
| สถานะ | ห้ามสื่อด้วยสีอย่างเดียว ต้องมีไอคอน/ข้อความ |
| โฟกัสคีย์บอร์ด | เห็นชัดทุกองค์ประกอบที่กดได้ |
| ปุ่ม | ใช้ `<button>` จริง ไม่ใช้ `<span>` ที่ผูก onclick (v0.5 ใช้ span) |
| พื้นที่แตะ | ≥ 40×40px |
