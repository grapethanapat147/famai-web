## ความเสี่ยงที่ต้องเฝ้า

| ความเสี่ยง | ผลกระทบ | ลดความเสี่ยงยังไง |
|---|---|---|
| **ข้อมูลเดิมไม่สะอาด** | นำเข้าแล้วเละ แก้ทีหลังยาก | ทำความสะอาดตามกฎ `00-yamaha-export-analysis.md` §5 และ **ยืนยันเรื่องวันที่ก่อน** |
| **พนักงานไม่ยอมใช้** | ระบบดีแต่ไม่มีคนใช้ = เสียเปล่า | นำร่องสาขาเดียว · ให้คนหน้างานร่วมออกแบบ · เทรนก่อนเปิด |
| **ขอบเขตงานบานปลาย** | ไม่จบสักที | ทำ Phase 1 ให้ใช้ได้จริงก่อน ห้ามแทรก Phase 2 เข้ามา |
| **ใบกำกับภาษีผิดกฎ** | มีค่าปรับ | ให้บัญชี/ผู้สอบบัญชีตรวจแบบฟอร์มก่อนเปิดใช้ |
| **ข้อมูลหาย** | หยุดธุรกิจ | สำรองรายวัน + ดาวน์โหลด dump เก็บนอกระบบเดือนละครั้ง + **ทดสอบกู้คืนจริง** |
| **PDPA** | มีความรับผิด | ทำ consent + สิทธิ์ลบ/แก้ + log ตั้งแต่ Phase 1 |
| **คนทำมีคนเดียว** | ป่วย/ลาออกแล้วงานหยุด | เอกสารครบ · โค้ดอยู่ใน Git · ไม่มีอะไรอยู่แค่ในหัวคน |
