## 🏗️ สถาปัตยกรรมที่เสนอ

เกณฑ์ที่ตั้งไว้: **ประหยัด + ดูแลง่าย ไม่ต้องมีทีม IT**

| ชั้น | เลือกใช้ |
|---|---|
| เว็บ | Next.js (App Router) + TypeScript บน Vercel |
| ฐานข้อมูล / Auth / ไฟล์แนบ | Supabase (PostgreSQL) |
| แจ้งเตือน | LINE Messaging API |

หลักการสำคัญ: **แยกข้อมูลรายสาขาที่ระดับฐานข้อมูล (Row Level Security)** ไม่ใช่ที่หน้าเว็บ
— ต่อให้ UI พลาด ข้อมูลสาขาอื่นก็ยังไม่รั่ว

รายละเอียดและค่าใช้จ่ายจริง จะอยู่ใน `docs/02-architecture.md`
