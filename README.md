## 🏗️ สถาปัตยกรรมที่เสนอ

เกณฑ์ที่ตั้งไว้: **ประหยัด + ดูแลง่าย ไม่ต้องมีทีม IT**

| ชั้น | เลือกใช้ |
|---|---|
| เว็บ | Next.js (App Router) + TypeScript บน Vercel |
| ฐานข้อมูล / Auth / ไฟล์แนบ | Supabase (PostgreSQL) |
| แจ้งเตือน | LINE Messaging API |

หลักการสำคัญ: **แยกข้อมูลรายสาขาที่ระดับฐานข้อมูล (Row Level Security)** ไม่ใช่ที่หน้าเว็บ
— ต่อให้ UI พลาด ข้อมูลสาขาอื่นก็ยังไม่รั่ว

รายละเอียดและค่าใช้จ่ายจริง (~฿1,660/เดือน) อยู่ใน `docs/02-architecture.md`

## 🔍 วิธีเปิด Prototype

ดับเบิลคลิก **`prototype/Famai_Prototype_v0.6.html`** ได้เลย ไม่ต้องติดตั้งอะไร
(ต่อเน็ตครั้งแรกเพื่อโหลดฟอนต์ — ไม่มีเน็ตก็ใช้ได้ แค่ใช้ฟอนต์สำรองในเครื่อง)

**ลองแบบนี้:**
1. เลือกผู้ใช้ในหน้า login → เมนูจะเปลี่ยนตามบทบาททันที (ช่างเห็น 6 เมนู · แอดมินเห็นครบ)
2. **ศูนย์ซ่อม** → พิมพ์ `E34RE-057401` แล้วกดค้นหา → ระบบดึงประวัติลูกค้าเก่ามาให้เอง
3. **ขายรถ** → เลือกเงินผ่อน → บันทึก → ระบบสร้างเคสสินเชื่อ ทะเบียน เงินค้างรับ และงานติดตามให้อัตโนมัติ
4. **ใบเสนอราคา** → เลือกรถคันที่ 2 → กดพิมพ์ (พิมพ์ได้จริง)
5. กด **โหมดลูกค้า** บนแถบบน → ต้นทุนและกำไรหายทุกหน้า
6. กด `/` เพื่อค้นหาทั้งระบบ

### v0.6 ต่างจาก v0.5 ตรงไหน

| | v0.5 | v0.6 |
|---|---|---|

| ลงเวลาเข้างาน | เวลาปลอม | **นาฬิกาจริง + คิด OT + หักสาย** |

⚠️ ยังเป็น**ต้นแบบ** — ข้อมูลอยู่ในหน้าเว็บ ปิดแล้วหาย ยังไม่มีฐานข้อมูลจริง
รถ 50 คันเป็นข้อมูลจริงจากไฟล์ยามาฮ่า ส่วนการขาย ลูกค้า พนักงาน อะไหล่ เป็นข้อมูลสมมุติ (ติดป้ายกำกับไว้ในหน้าจอ)

## เปิดดูต้นแบบ

`index.html` ที่รากคือ **ตัวจริงที่ deploy** — แก้ที่ไฟล์นี้ไฟล์เดียว
`prototype/` เก็บเวอร์ชันเก่า (v0.5 · v0.6 · v0.7) ไว้เทียบเท่านั้น

เปิดจากเครื่องได้ตรง ๆ หรือดูที่ลิงก์ที่ deploy ไว้

### Deploy

รีโปนี้ต่อกับ Vercel ผ่าน Git แล้ว — push แล้ว deploy อัตโนมัติ
`vercel.json` ตั้ง `X-Robots-Tag: noindex` และ `Referrer-Policy: no-referrer` ไว้
เพราะต้นแบบมีเลขเครื่อง เลขถัง และต้นทุนจริง

> สำหรับ**ระบบจริง** เอกสารแนะนำ Cloudflare Pages แทน เพราะ Vercel Hobby
> ห้ามใช้เชิงพาณิชย์ตามเงื่อนไขบริการ และ Pro คิดรายที่นั่งจนเกินงบ ฿1,000
> — ต้นแบบที่ยังไม่มีข้อมูลลูกค้าจริงใช้ Vercel ดูก่อนได้
